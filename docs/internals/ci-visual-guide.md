# Visual Guide Workflow Specification

**Workflow:** `.github/workflows/visual-guide.yml`  
**Status:** Accepted  
**Last updated:** 2026-06-29

## Purpose

Validate and publish the static visual guide generated by `cargo xtask
visual-guide`.

## Triggers

| Trigger | Behavior |
|---|---|
| Pull request touching visual-guide sources/assets/workflow | Run `visual-guide --check`; do not deploy |
| Push to `main` touching visual-guide sources/assets/workflow | Validate, build generated HTML, upload Pages artifact, deploy to GitHub Pages |
| Manual dispatch | Same as push behavior |

## Jobs

| Job | Purpose | Output |
|---|---|---|
| `build-deploy` | Build or validate the guide and deploy on non-PR runs | GitHub Pages artifact and deployment URL |

## Security constraints

- Immutable GitHub Actions are SHA-pinned with version comments.
- `dtolnay/rust-toolchain@stable` remains a rolling ref by policy.
- Permissions are limited to `contents: read`, `pages: write`, and
  `id-token: write` for Pages deployment.

## Change management

Any change to deployment behavior must update this specification and
`docs/architecture.md` §15.3 in the same PR.
