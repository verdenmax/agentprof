# M1.6.4 — Speedscope JSON + HTML export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two new export formats to `agentprof analyze` — Speedscope evented JSON (for upload to speedscope.app) and self-contained static HTML (no JS, for sharing via email / Slack / PR).

**Architecture:** Pure data transformations live in `agentprof-core::export::{speedscope, svg_flamegraph}` (lib, reusable, unit-testable). Cli `cmd::format::{speedscope, html}` are thin orchestration shells that call core + serialize/render. HTML uses askama 0.16 compile-time templates with embedded CSS (no JS, no runtime asset bundling). New `ExportWarning` enum surfaces span-overlap adjustments without polluting `DeriveWarning`.

**Tech Stack:** Rust 2021 (MSRV 1.78); serde + serde_json for JSON; chrono for time deltas; askama 0.16 for HTML template compilation; std::fmt + include_str! for SVG/CSS generation; insta for snapshot tests; assert_cmd + predicates for CLI integration.

**Spec:** [`docs/superpowers/specs/2026-05-31-m1.6.4-speedscope-and-html-export-design.md`](../specs/2026-05-31-m1.6.4-speedscope-and-html-export-design.md) (commit `0bac266`)

# fixture: with-span-overlap

A synthetic Copilot CLI session with **one assistant turn containing two tool
executions whose time spans overlap**:

- Tool A: `bash` — started 13:00:01, ended 13:00:03 (2s)
- Tool B: `bash` — started 13:00:02, ended 13:00:04 (2s; overlaps with A by 1s)

## Purpose

The episode derivation layer (`agentprof-core::episode::derive_episodes`)
intentionally **does not** enforce strict span nesting — adapters may report
overlapping tool calls (e.g. when a tool is run in a subshell or when clock
skew exists across event emitters). The derive layer accepts the data as
reported.

The Speedscope export layer (`agentprof-core::export::speedscope`), however,
MUST emit strictly-nested open/close events for speedscope.app to render
correctly. When it detects overlap within a single turn, it shifts the later
call's `started_at` to `prev.ended_at + 1ms` and emits an
`ExportWarning::SpanAdjustedForSpeedscope`. The two tool calls remain in the
output but their effective timing is approximated.

This fixture exercises that branch.
```

//! Warnings emitted by the `agentprof-core::export` module.
//!
//! Unlike `crate::error::ParseWarning` (parse layer) and
//! `crate::episode::DeriveWarning` (derive layer), `ExportWarning` is
//! produced by the export pipelines that re-shape `Episodes` into
//! external formats (e.g. Speedscope's strict-nesting requirement).

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use thiserror::Error;

/// A non-fatal observation surfaced during export.
///
/// `agentprof-cli` prints these to stderr (one line each) and does not
/// change the process exit code on their account.
///
/// # Examples
///
/// ```
/// use agentprof_core::export::ExportWarning;
/// use chrono::Utc;
/// let w = ExportWarning::SpanAdjustedForSpeedscope {
///     tool_name: "bash".to_string(),
///     original_start: Utc::now(),
///     adjusted_start: Utc::now(),
/// };
/// // Display impl is provided by `thiserror::Error`.
/// let _msg = format!("{w}");
/// ```
#[derive(Debug, Clone, PartialEq, Error, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "snake_case")]
#[non_exhaustive]
pub enum ExportWarning {
    /// A tool span overlapped a sibling span in the same turn; Speedscope
    /// requires strict nesting, so the later span was shifted by 1 ms.
    ///
    /// Reported timing for the affected call is approximated; the warning
    /// lets the user know.
    #[error(
        "span adjusted for speedscope: tool={tool_name} original_start={original_start} \
         adjusted_start={adjusted_start}"
    )]
    SpanAdjustedForSpeedscope {
        /// Name of the tool whose span was shifted.
        tool_name: String,
        /// Originally reported `started_at`.
        original_start: DateTime<Utc>,
        /// Adjusted `started_at` actually emitted to the profile.
        adjusted_start: DateTime<Utc>,
    },
}
```

//! Speedscope evented JSON profile emitter.
//!
//! See [ADR-0007](../../../../../docs/internals/adr-0007-speedscope-export.md)
//! for the decisions behind frame naming, dedup, orphan handling, and
//! span overlap adjustment.

use std::collections::BTreeMap;

use chrono::{DateTime, Duration, Utc};
use serde::{Deserialize, Serialize};

use crate::episode::Episodes;
use crate::export::ExportWarning;
use crate::model::ToolSource;
use crate::adapter::SessionMeta;

/// Root document of a Speedscope file.
///
/// Conforms to the schema at <https://github.com/jlfwong/speedscope/blob/main/file-format.md>.
///
/// # Examples
///
/// ```
/// use agentprof_core::export::speedscope::SpeedscopeProfile;
/// assert!(SpeedscopeProfile::SCHEMA_URL.starts_with("https://"));
/// ```
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
#[non_exhaustive]
pub struct SpeedscopeProfile {
    /// Schema URL (constant, see [`Self::SCHEMA_URL`]).
    #[serde(rename = "$schema")]
    pub schema: String,
    /// Human-readable profile name (typically "agentprof <short-id> <agent>").
    pub name: String,
    /// Exporter identifier (typically "agentprof v<version>").
    pub exporter: String,
    /// Shared frame table referenced by event records.
    pub shared: Shared,
    /// One or more profiles. agentprof emits exactly one.
    pub profiles: Vec<Profile>,
}

impl SpeedscopeProfile {
    /// Canonical schema URL used in the `$schema` field.
    pub const SCHEMA_URL: &'static str = "https://www.speedscope.app/file-format-schema.json";
}

/// Frame table holder.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[non_exhaustive]
pub struct Shared {
    /// All frames referenced by every profile's events, by index.
    pub frames: Vec<Frame>,
}

/// One labeled "frame" (function-like unit). Referenced by index from events.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[non_exhaustive]
pub struct Frame {
    /// Display name shown in the speedscope viewer.
    pub name: String,
}

/// One profile (timeline of events). agentprof always emits one, of type
/// [`ProfileType::Evented`].
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
#[non_exhaustive]
pub struct Profile {
    /// Encoding type — agentprof always uses [`ProfileType::Evented`].
    #[serde(rename = "type")]
    pub ty: ProfileType,
    /// Profile display name.
    pub name: String,
    /// Time unit string ("milliseconds" for agentprof).
    pub unit: String,
    /// Earliest event time (always 0 — agentprof normalizes to session start).
    pub start_value: i64,
    /// Latest event time, in `unit`.
    pub end_value: i64,
    /// Open/close events, in chronological order.
    pub events: Vec<Event>,
}

/// Profile encoding type.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
#[non_exhaustive]
pub enum ProfileType {
    /// Open/close events, suitable for hierarchical event-driven profilers.
    Evented,
}

/// One open or close event in a profile.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[non_exhaustive]
pub struct Event {
    /// `O` = open (push frame), `C` = close (pop frame).
    #[serde(rename = "type")]
    pub ty: EventType,
    /// Time offset from `Profile.start_value`, in `Profile.unit`.
    pub at: i64,
    /// Index into `Shared.frames`.
    pub frame: usize,
}

/// `O`pen / `C`lose discriminant.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
#[non_exhaustive]
pub enum EventType {
    /// Frame opens (push onto stack).
    #[serde(rename = "O")]
    Open,
    /// Frame closes (pop from stack).
    #[serde(rename = "C")]
    Close,
}

/// Convert episodes + metadata to a Speedscope profile.
///
/// The resulting `SpeedscopeProfile` is timestamp-normalized so that the
/// session's first event sits at `at = 0` (D-10); this makes the output
/// reproducible for snapshot tests.
///
/// Returns the profile plus any [`ExportWarning`]s emitted while
/// adjusting for Speedscope's strict-nesting requirement (D-15).
///
/// # Examples
///
/// ```
/// use agentprof_core::adapter::SessionMeta;
/// use agentprof_core::episode::Episodes;
/// use agentprof_core::export::speedscope::to_speedscope;
/// let episodes = Episodes::new();
/// let meta = SessionMeta::test_default();
/// let (profile, warnings) = to_speedscope(&episodes, &meta, "0.0.0");
/// assert_eq!(profile.profiles.len(), 1);
/// assert!(warnings.is_empty());
/// ```
#[must_use]
pub fn to_speedscope(
    episodes: &Episodes,
    meta: &SessionMeta,
    agentprof_version: &str,
) -> (SpeedscopeProfile, Vec<ExportWarning>) {
    // 1. Determine session bounds.
    let session_start = meta.started_at;
    let session_end = compute_session_end(episodes, session_start);
    let total_ms = duration_ms(session_end - session_start);

    // 2. Build the canonical frame order: session, turn-1..turn-N, then
    //    every distinct tool/hook/skill name (BTreeMap iteration → sorted).
    let mut frame_names: Vec<String> = Vec::new();
    frame_names.push("session".to_string());

    // Turn frames (assigned ordinals 1..N in source order; "(open)" suffix
    // for un-closed turns).
    for (ordinal, turn) in episodes.turns.iter().enumerate() {
        let name = if turn.ended_at.is_none() {
            format!("turn-{} (open)", ordinal + 1)
        } else {
            format!("turn-{}", ordinal + 1)
        };
        frame_names.push(name);
    }

    // Orphan-turn frame (synthetic; only appended if any orphan exists).
    let has_orphan_tool_calls = episodes
        .tools
        .values()
        .any(|t| t.calls.iter().any(|c| c.turn_id.is_none()));
    if has_orphan_tool_calls {
        frame_names.push("turn-orphan".to_string());
    }

    // Tool / hook / skill name frames (sorted, deduplicated).
    let mut leaf_names: std::collections::BTreeSet<String> = Default::default();
    for tool in episodes.tools.values() {
        let display = format_tool_frame_name(&tool.name, &tool.source);
        leaf_names.insert(display);
    }
    for hook in episodes.hooks.values() {
        leaf_names.insert(format!("hook:{}", hook.name));
    }
    for skill in episodes.skills.values() {
        for inv in &skill.invocations {
            leaf_names.insert(format!("skill:{}:{}", skill.name, inv.tool_name));
        }
    }
    frame_names.extend(leaf_names);

    // Index lookup.
    let frame_index: BTreeMap<String, usize> = frame_names
        .iter()
        .enumerate()
        .map(|(i, n)| (n.clone(), i))
        .collect();

    // 3. Build events.
    let mut events: Vec<Event> = Vec::new();
    let mut warnings: Vec<ExportWarning> = Vec::new();

    // Session open.
    events.push(Event { ty: EventType::Open, at: 0, frame: 0 });

    for (ordinal, turn) in episodes.turns.iter().enumerate() {
        let turn_name = if turn.ended_at.is_none() {
            format!("turn-{} (open)", ordinal + 1)
        } else {
            format!("turn-{}", ordinal + 1)
        };
        let turn_frame = frame_index[&turn_name];
        let turn_start_ms = duration_ms(turn.started_at - session_start);
        let turn_end_ms = turn
            .ended_at
            .map_or(total_ms, |e| duration_ms(e - session_start));

        events.push(Event { ty: EventType::Open, at: turn_start_ms, frame: turn_frame });

        // Collect child calls (tool + hook + skill) inside this turn, sorted by
        // span.started_at, and emit them with overlap-adjusted nesting.
        let mut children: Vec<(DateTime<Utc>, DateTime<Utc>, String, String)> = Vec::new();
        for tool_ref in &turn.tool_calls {
            if let Some(tool) = episodes.tools.get(&tool_ref.name) {
                if let Some(call) = tool.calls.get(tool_ref.index) {
                    let name = format_tool_frame_name(&tool_ref.name, &tool.source);
                    children.push((call.span.started_at, call.span.ended_at, name, tool_ref.name.clone()));
                }
            }
        }
        for hook_ref in &turn.hook_calls {
            if let Some(hook) = episodes.hooks.get(&hook_ref.name) {
                if let Some(call) = hook.calls.get(hook_ref.index) {
                    children.push((call.span.started_at, call.span.ended_at, format!("hook:{}", hook_ref.name), hook_ref.name.clone()));
                }
            }
        }
        for skill_ref in &turn.skill_calls {
            if let Some(skill) = episodes.skills.get(&skill_ref.name) {
                if let Some(inv) = skill.invocations.get(skill_ref.index) {
                    children.push((inv.span.started_at, inv.span.ended_at, format!("skill:{}:{}", skill_ref.name, inv.tool_name), format!("{}:{}", skill_ref.name, inv.tool_name)));
                }
            }
        }
        children.sort_by_key(|c| c.0);

        let mut last_end = turn.started_at;
        for (original_start, original_end, display, display_for_warning) in children {
            let (effective_start, effective_end) = if original_start < last_end {
                // Overlap → push warning and adjust.
                let adjusted = last_end + Duration::milliseconds(1);
                warnings.push(ExportWarning::SpanAdjustedForSpeedscope {
                    tool_name: display_for_warning.clone(),
                    original_start,
                    adjusted_start: adjusted,
                });
                // Ensure end is still > start so we get a non-zero rect.
                let adj_end = if original_end <= adjusted {
                    adjusted + Duration::milliseconds(1)
                } else {
                    original_end
                };
                (adjusted, adj_end)
            } else {
                (original_start, original_end)
            };
            // Clamp end into the parent turn's end window.
            let clamped_end = effective_end.min(turn.ended_at.unwrap_or(session_end));
            let frame_idx = frame_index[&display];
            events.push(Event {
                ty: EventType::Open,
                at: duration_ms(effective_start - session_start),
                frame: frame_idx,
            });
            events.push(Event {
                ty: EventType::Close,
                at: duration_ms(clamped_end - session_start),
                frame: frame_idx,
            });
            last_end = clamped_end;
        }

        events.push(Event { ty: EventType::Close, at: turn_end_ms, frame: turn_frame });
    }

    // Orphan tool calls — collect, sort, emit under synthetic turn-orphan.
    if has_orphan_tool_calls {
        let orphan_frame = frame_index["turn-orphan"];
        let mut orphans: Vec<(DateTime<Utc>, DateTime<Utc>, String)> = Vec::new();
        for tool in episodes.tools.values() {
            for call in &tool.calls {
                if call.turn_id.is_none() {
                    let display = format_tool_frame_name(&tool.name, &tool.source);
                    orphans.push((call.span.started_at, call.span.ended_at, display));
                }
            }
        }
        orphans.sort_by_key(|o| o.0);
        if let (Some(first), Some(last)) = (orphans.first(), orphans.last()) {
            let orphan_start_ms = duration_ms(first.0 - session_start);
            let orphan_end_ms = duration_ms(last.1 - session_start);
            events.push(Event { ty: EventType::Open, at: orphan_start_ms, frame: orphan_frame });
            for (s, e, display) in orphans {
                let frame_idx = frame_index[&display];
                events.push(Event { ty: EventType::Open, at: duration_ms(s - session_start), frame: frame_idx });
                events.push(Event { ty: EventType::Close, at: duration_ms(e - session_start), frame: frame_idx });
            }
            events.push(Event { ty: EventType::Close, at: orphan_end_ms, frame: orphan_frame });
        }
    }

    // Session close.
    events.push(Event { ty: EventType::Close, at: total_ms, frame: 0 });

    let profile = SpeedscopeProfile {
        schema: SpeedscopeProfile::SCHEMA_URL.to_string(),
        name: format!("agentprof {} {}", short_id(&meta.session_id), agent_label(meta)),
        exporter: format!("agentprof v{agentprof_version}"),
        shared: Shared { frames: frame_names.into_iter().map(|name| Frame { name }).collect() },
        profiles: vec![Profile {
            ty: ProfileType::Evented,
            name: "wall-clock".to_string(),
            unit: "milliseconds".to_string(),
            start_value: 0,
            end_value: total_ms,
            events,
        }],
    };

    (profile, warnings)
}

/// Format a tool name with its source prefix per D-11.
fn format_tool_frame_name(name: &str, source: &ToolSource) -> String {
    match source {
        ToolSource::Builtin => name.to_string(),
        ToolSource::Mcp { server } => {
            // Strip the `mcp__<server>__` prefix from name if present, so we
            // get `mcp:<server>::<tool>` (clean form) rather than
            // `mcp:<server>::mcp__<server>__<tool>`.
            let leaf = name
                .strip_prefix(&format!("mcp__{server}__"))
                .unwrap_or(name);
            format!("mcp:{server}::{leaf}")
        }
        ToolSource::Skill { name: skill } => {
            let leaf = name
                .strip_prefix(&format!("skill__{skill}__"))
                .unwrap_or(name);
            format!("skill:{skill}:{leaf}")
        }
    }
}

fn compute_session_end(episodes: &Episodes, session_start: DateTime<Utc>) -> DateTime<Utc> {
    let mut latest = session_start;
    for turn in &episodes.turns {
        if let Some(end) = turn.ended_at {
            if end > latest { latest = end; }
        } else if turn.started_at > latest {
            latest = turn.started_at;
        }
        for tool_ref in &turn.tool_calls {
            if let Some(tool) = episodes.tools.get(&tool_ref.name) {
                if let Some(call) = tool.calls.get(tool_ref.index) {
                    if call.span.ended_at > latest { latest = call.span.ended_at; }
                }
            }
        }
    }
    for tool in episodes.tools.values() {
        for call in &tool.calls {
            if call.span.ended_at > latest { latest = call.span.ended_at; }
        }
    }
    latest
}

fn duration_ms(d: Duration) -> i64 {
    d.num_milliseconds().max(0)
}

fn short_id(session_id: &str) -> String {
    session_id.chars().take(8).collect()
}

fn agent_label(meta: &SessionMeta) -> &'static str {
    // Currently always copilot; expand when other adapters land.
    let _ = meta;
    "copilot"
}

        let session_end = compute_session_end(episodes, session_start);
        let total_ms = (session_end - session_start).num_milliseconds().max(1);

        let turn_count = episodes.turns.len().max(1) as i64;
        let viewbox_w = (turn_count * PER_TURN_VIEWBOX).clamp(MIN_VIEWBOX_W, MAX_VIEWBOX_W);
        let viewbox_h = ROW_HEIGHT * (MAX_DEPTH as i64 + 1);

        let mut rects: Vec<Rect> = Vec::new();

        // Row 0: session.
        rects.push(Rect {
            x: 0,
            y: 0,
            w: viewbox_w,
            h: ROW_HEIGHT,
            fill: COLOR_SESSION,
            label: "session".to_string(),
            title: format!("session ({total_ms} ms)"),
        });

        for turn in &episodes.turns {
            let turn_start = (turn.started_at - session_start).num_milliseconds().max(0);
            let turn_end = turn.ended_at.unwrap_or(session_end);
            let turn_dur = (turn_end - turn.started_at).num_milliseconds().max(0);
            let x = turn_start * viewbox_w / total_ms;
            let w = (turn_dur * viewbox_w / total_ms).max(1);
            let label = format!("turn-{}", turn.id);
            rects.push(Rect {
                x,
                y: ROW_HEIGHT,
                w,
                h: ROW_HEIGHT,
                fill: COLOR_TURN,
                label: label.clone(),
                title: format!("{label} ({turn_dur} ms)"),
            });

            // Turn children at row 2; deeper nesting beyond row 2 is collapsed
            // (M1.6.4 doesn't track call-graph nesting).
            for tool_ref in &turn.tool_calls {
                if let Some(tool) = episodes.tools.get(&tool_ref.name) {
                    if let Some(call) = tool.calls.get(tool_ref.index) {
                        let (cx, cw) = position(call.span.started_at, call.span.ended_at, session_start, total_ms, viewbox_w);
                        let fill = color_for_source(&tool.source);
                        let label = display_name(&tool.name, &tool.source);
                        rects.push(Rect {
                            x: cx,
                            y: ROW_HEIGHT * 2,
                            w: cw,
                            h: ROW_HEIGHT,
                            fill,
                            label: label.clone(),
                            title: format!("{label}"),
                        });
                    }
                }
            }
            for hook_ref in &turn.hook_calls {
                if let Some(hook) = episodes.hooks.get(&hook_ref.name) {
                    if let Some(call) = hook.calls.get(hook_ref.index) {
                        let (cx, cw) = position(call.span.started_at, call.span.ended_at, session_start, total_ms, viewbox_w);
                        let label = format!("hook:{}", hook_ref.name);
                        rects.push(Rect {
                            x: cx,
                            y: ROW_HEIGHT * 2,
                            w: cw,
                            h: ROW_HEIGHT,
                            fill: COLOR_HOOK,
                            label: label.clone(),
                            title: label.clone(),
                        });
                    }
                }
            }
            for skill_ref in &turn.skill_calls {
                if let Some(skill) = episodes.skills.get(&skill_ref.name) {
                    if let Some(inv) = skill.invocations.get(skill_ref.index) {
                        let (cx, cw) = position(inv.span.started_at, inv.span.ended_at, session_start, total_ms, viewbox_w);
                        let label = format!("skill:{}:{}", skill_ref.name, inv.tool_name);
                        rects.push(Rect {
                            x: cx,
                            y: ROW_HEIGHT * 2,
                            w: cw,
                            h: ROW_HEIGHT,
                            fill: COLOR_SKILL,
                            label: label.clone(),
                            title: label.clone(),
                        });
                    }
                }
            }
        }

        Self { rects, viewbox_w, viewbox_h }
    }

    /// Serialize to a self-contained SVG string suitable for `include`
    /// into HTML.
    #[must_use]
    pub fn into_svg_string(self) -> String {
        let mut out = String::with_capacity(2048);
        let _ = write!(
            &mut out,
            r#"<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {w} {h}" width="100%" preserveAspectRatio="xMidYMid meet" font-family="sans-serif" font-size="12">"#,
            w = self.viewbox_w,
            h = self.viewbox_h,
        );
        for r in &self.rects {
            let _ = write!(
                &mut out,
                r#"<g><rect x="{x}" y="{y}" width="{w}" height="{h}" fill="{fill}" stroke="white" stroke-width="0.5"><title>{title}</title></rect>"#,
                x = r.x, y = r.y, w = r.w, h = r.h, fill = r.fill,
                title = escape_xml(&r.title),
            );
            if r.w >= TEXT_MIN_RECT_WIDTH {
                let _ = write!(
                    &mut out,
                    r#"<text x="{tx}" y="{ty}" fill="white" pointer-events="none">{label}</text>"#,
                    tx = r.x + 4,
                    ty = r.y + r.h - 18,  // bottom-of-row baseline-ish
                    label = escape_xml(truncate(&r.label, ((r.w - 6) / 7) as usize)),
                );
            }
            out.push_str("</g>");
        }
        out.push_str("</svg>");
        out
    }
}

fn position(
    start: DateTime<Utc>,
    end: DateTime<Utc>,
    session_start: DateTime<Utc>,
    total_ms: i64,
    viewbox_w: i64,
) -> (i64, i64) {
    let s = (start - session_start).num_milliseconds().max(0);
    let e = (end - session_start).num_milliseconds().max(s);
    let x = s * viewbox_w / total_ms;
    let w = ((e - s) * viewbox_w / total_ms).max(1);
    (x, w)
}

fn color_for_source(source: &ToolSource) -> &'static str {
    match source {
        ToolSource::Builtin => COLOR_BUILTIN,
        ToolSource::Mcp { .. } => COLOR_MCP,
        ToolSource::Skill { .. } => COLOR_SKILL,
    }
}

fn display_name(raw: &str, source: &ToolSource) -> String {
    match source {
        ToolSource::Builtin => raw.to_string(),
        ToolSource::Mcp { server } => {
            let leaf = raw.strip_prefix(&format!("mcp__{server}__")).unwrap_or(raw);
            format!("mcp:{server}::{leaf}")
        }
        ToolSource::Skill { name } => {
            let leaf = raw.strip_prefix(&format!("skill__{name}__")).unwrap_or(raw);
            format!("skill:{name}:{leaf}")
        }
    }
}

fn truncate(s: &str, max_chars: usize) -> &str {
    if max_chars == 0 { return ""; }
    match s.char_indices().nth(max_chars) {
        Some((idx, _)) => &s[..idx],
        None => s,
    }
}

fn escape_xml(s: &str) -> String {
    s.replace('&', "&amp;")
        .replace('<', "&lt;")
        .replace('>', "&gt;")
        .replace('"', "&quot;")
        .replace('\'', "&apos;")
}

fn compute_session_end(episodes: &Episodes, session_start: DateTime<Utc>) -> DateTime<Utc> {
    let mut latest = session_start;
    for turn in &episodes.turns {
        if let Some(end) = turn.ended_at {
            if end > latest { latest = end; }
        }
    }
    for tool in episodes.tools.values() {
        for call in &tool.calls {
            if call.span.ended_at > latest { latest = call.span.ended_at; }
        }
    }
    latest
}

fn format_duration_short(report: &AnalysisReport) -> String {
    let total: chrono::Duration = report
        .turn_summary
        .iter()
        .filter_map(|r| r.duration)
        .fold(chrono::Duration::zero(), |a, b| a + b);
    if total.num_milliseconds() == 0 { return "0 ms".to_string(); }
    let ms = total.num_milliseconds();
    if ms < 1000 { format!("{ms} ms") }
    else if ms < 60_000 { format!("{:.1} s", ms as f64 / 1000.0) }
    else { format!("{:.1} min", ms as f64 / 60_000.0) }
}

```markdown
# ADR-0007 — Speedscope evented format + frame naming + overlap adjustment

> **Status:** Accepted
> **Date:** 2026-05-31
> **Deciders:** agentprof team
> **Supersedes:** —
> **Superseded by:** —
> **Spec:** [`2026-05-31-m1.6.4-speedscope-and-html-export-design.md`](../superpowers/specs/2026-05-31-m1.6.4-speedscope-and-html-export-design.md)
> **Plan:** [`2026-05-31-m1.6.4-speedscope-and-html-export.md`](../superpowers/plans/2026-05-31-m1.6.4-speedscope-and-html-export.md)

## Context

M1.6.4 introduces a `--export speedscope` flag that emits a JSON file
consumable by the [speedscope.app](https://speedscope.app) interactive
flamegraph viewer. The Speedscope file-format spec at
<https://github.com/jlfwong/speedscope/blob/main/file-format.md> describes
three encodings (evented, sampled, speedscope-native) and requires that
events be **strictly nested** (every Open has a matching Close that pops
the same frame). agentprof's `Episodes` model does NOT enforce strict
nesting on tool/hook/skill calls — adapters may report overlap (e.g. clock
skew, sub-shells), and the derive layer accepts the data as reported.

This ADR documents the decisions that bridge those two worlds.

## Decision

### D-1 (M1.6.4): Use the "evented" format

`profiles[*].type = "evented"`. Reasons:
1. Maps 1-to-1 with agentprof's own open/close event model — no
   re-sampling or aggregation needed.
2. Preserves exact timing for non-overlapping spans.
3. Hierarchical (sampled format would lose the call-graph structure).

Sampled format is the natural future home for tokenizer-based weights
(Phase 2+).

### D-9: `unit = "milliseconds"`, integer `at`

Speedscope accepts any numeric unit but renders integers more cleanly. The
event JSONL stream has RFC3339 timestamps with millisecond granularity,
so finer precision would be false confidence.

### D-10: Timestamp anchor = session.started_at → at:0

All event `at` values are deltas from `session.started_at` rather than
absolute Unix timestamps. Reasons:
1. Snapshot tests are reproducible across runs (no wall-clock drift).
2. Speedscope's "left-heavy" view still works (it uses durations, not
   absolute times).
3. Files are smaller (4-5 digit integers vs 13-digit Unix ms).

### D-11: Frame naming with source prefix

| Source | Frame name |
|---|---|
| Builtin tool (bash, view, etc.) | `<name>` |
| MCP tool | `mcp:<server>::<leaf>` |
| Hook | `hook:<name>` |
| Skill invocation | `skill:<skill>:<tool>` |
| Synthetic | `session`, `turn-<N>`, `turn-<N> (open)`, `turn-orphan` |

Prefixes prevent collision (e.g. a builtin `read` vs an MCP `mcp:fs::read`)
and let the viewer's left-heavy / top-down views group by source.

### D-12: Global frame dedup by name

`shared.frames` contains each unique name exactly once; events reference
frames by index. Required for speedscope's left-heavy view to merge calls
to the same tool across turns. Naming order: `session`, `turn-1..N`,
`turn-orphan` (if any), then BTreeMap-sorted leaf names.

### D-13: Open turn → `(open)` suffix + synthetic close at last event time

If `turn.ended_at == None`, the frame is named `turn-<N> (open)` and we
emit a synthetic `Close` at the timestamp of the last event in the
session. This keeps the profile strictly nested while giving users a
visible signal that the turn never completed.

### D-14: Orphan tool calls → synthetic `turn-orphan` frame

Tool calls with `turn_id == None` (orphans per ADR-0004) are grouped under
a synthetic `turn-orphan` frame appended after all real turns. The frame
spans from the first orphan's start to the last orphan's end.

### D-15: Span overlap → auto-adjust + ExportWarning

If two child spans within the same turn overlap (later.started_at <
earlier.ended_at), the later span's effective start is shifted to
`earlier.ended_at + 1ms` (and if its original_end <= adjusted_start, end
is shifted to `adjusted_start + 1ms`). An
`ExportWarning::SpanAdjustedForSpeedscope` is pushed for each adjustment;
the cli prints these to stderr.

Rejected alternatives:
- Fail-loud (refuse to export) — too disruptive for what's usually a clock
  skew artifact.
- Silently re-order — loses signal; users wouldn't know their timing was
  approximated.

### D-16: New `ExportWarning` type, NOT a `DeriveWarning` variant

`DeriveWarning` is the derive layer's observation of input data quality.
Span-overlap adjustment is a downstream side-effect of the export pipeline
(the derive layer accepted the overlap as valid). Adding a
`DeriveWarning` variant would have polluted derive's snapshot tests
without semantic justification.

`ExportWarning` lives in `agentprof-core::export` with its own module;
future formats (CSV, HTML-specific) get their own variants.

## Consequences

- Speedscope output is **strictly nested** — guarantees the viewer renders
  correctly.
- Overlapping spans lose timing fidelity (≤ 1 ms shift), but the data is
  preserved and the user is notified.
- Frame naming convention is **load-bearing** across exporters: the same
  prefix scheme is used by `svg_flamegraph` for color coding (D-5).
- Future tokenizer (Phase 2) will likely emit a second `Profile` with
  `unit = "tokens"`, demonstrating the multi-profile capability of the
  format.

## Implementation

- Module: `agentprof-core::export::speedscope` (lib, pure transformation)
- Module: `agentprof-core::export::warning` (`ExportWarning` enum)
- CLI wrapper: `agentprof-cli::cmd::format::speedscope`
- Tests: 4 fixture-based core tests (`with-skill-invoked`,
  `cross-turn-tool`, `with-span-overlap`, `with-aborts`) + 1 snapshot
  in cli (`cli__analyze_speedscope__with_skill_invoked.snap`)
- Smoke: upload generated JSON to https://speedscope.app
