# M2.3 Web Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `agentprof serve` — embedded HTTP dashboard with browser-driven auto-refresh, mirroring the 5 existing read surfaces (sessions list / single session / aggregate / mcp-waste list+detail) via reused askama templates + vanilla JS poller.

**Architecture:** New `cmd::serve` module in `agentprof-cli`, gated behind a `web` Cargo feature. Built on the M2.2 OTLP receiver's axum/tower stack (already in dep tree). Each view has 2 HTTP endpoints: `GET /<view>` (full HTML with dashboard chrome) + `GET /api/<view>.html` (main-panel-only HTML chunk for JS swap). Bundled vanilla JS (~80 LOC) polls `/api/*.html` on a user-configurable interval (default 5 s) and replaces `<main>` content via `innerHTML`. Server reads SQLite store directly via `SqliteDataSource` (M2.1 trait); no caching layer. Default bind `127.0.0.1:4329`; non-loopback bind logs a warning; no auth in this wave.

**Tech Stack:** Rust 1.78 (no MSRV change) / `axum 0.7` + `askama` + `tower` (all already in dep tree via `agentprof-storage/otlp`) / vanilla JS bundled via `include_str!` / `assert_cmd` + `reqwest` for e2e tests / `insta` for HTML snapshots / `tokio` runtime (already used by `ingest-otlp`).

**Reference docs:**
- Spec: `docs/superpowers/specs/2026-06-11-m2.3-web-dashboard-design.md` (commit `014e191`)
- Q-7.2 closure: `docs/plan.md` §7.2 "Web dashboard" open question

```rust
//! `agentprof serve` — embedded HTTP dashboard (M2.3).
//!
//! Runs an HTTP server bound to `--bind` (default `127.0.0.1:4329`)
//! that renders the same data the existing CLI surfaces produce, with
//! browser-driven auto-refresh. Requires the `--storage-path` SQLite
//! store to be populated (run `agentprof db ingest` or
//! `agentprof ingest-otlp` first).
//!
//! See ADR-0024 for architecture decisions and
//! `docs/superpowers/specs/2026-06-11-m2.3-web-dashboard-design.md`
//! for the design spec.

use std::net::SocketAddr;
use std::path::PathBuf;

use anyhow::Result;
use clap::Args;

/// CLI arguments for `agentprof serve`.
#[derive(Debug, Args)]
pub struct ServeCmd {
    /// Address to bind the HTTP listener on. Default `127.0.0.1:4329`.
    /// Non-loopback bind logs a warning recommending a reverse proxy.
    #[arg(long, value_name = "ADDR")]
    pub bind: Option<SocketAddr>,

    /// Path to the SQLite store. Overrides config-file `[storage] path`
    /// and the `AGENTPROF_STORAGE_PATH` env var.
    #[arg(long, value_name = "PATH", env = "AGENTPROF_STORAGE_PATH")]
    pub storage_path: Option<PathBuf>,

    /// Browser-side default poll interval in seconds. Range 1..=60.
    /// User can override per-tab via the toolbar (persisted in localStorage).
    #[arg(long, value_name = "S", default_value = "5", value_parser = clap::value_parser!(u8).range(1..=60))]
    pub interval_default: u8,

    /// Skip the default "open browser on start" behavior.
    #[arg(long)]
    pub no_open: bool,

    /// Suppress per-request tracing output.
    #[arg(long)]
    pub quiet: bool,
}

/// Sync entry point: builds a tokio runtime and runs [`run_async`].
///
/// # Errors
///
/// Returns `anyhow::Error` carrying an `ExitKind` per
/// `docs/architecture.md` §8.1. T3 fills in the actual handler.
pub fn run(cmd: ServeCmd) -> Result<()> {
    // T3 will wire in the tokio runtime; for now, prove the subcommand dispatches.
    println!(
        "agentprof serve: bind={:?} storage_path={:?} interval_default={} no_open={} quiet={}",
        cmd.bind, cmd.storage_path, cmd.interval_default, cmd.no_open, cmd.quiet,
    );
    Ok(())
}
```

- [ ] **Step 1: Create `state.rs`**

```rust
//! Per-request shared state for the dashboard handlers (M2.3 T3).

use std::sync::{Arc, Mutex};

use agentprof_storage::Db;

/// Shared state injected into every dashboard route handler via
/// axum's `State` extractor.
///
/// `db` is wrapped in `Arc<Mutex<Db>>` mirroring M2.2's
/// `StorageFlushSink` pattern — rusqlite is sync; the mutex
/// serializes connection access across concurrent request handlers
/// without spawning a connection pool (a single dashboard user
/// generates trivially low load).
#[derive(Clone)]
pub struct AppState {
    /// SQLite store handle.
    pub db: Arc<Mutex<Db>>,
    /// Browser-side default poll interval (seconds, 1..=60). Embedded
    /// into the HTML chrome so the JS poller picks it up before the
    /// user touches the toolbar.
    pub interval_default: u8,
}
```

- [ ] **Step 2: Wire DB open into `cmd/serve/mod.rs::run`**

Replace the T2 stub `run()` with:

```rust
pub fn run(cmd: ServeCmd) -> Result<()> {
    // Resolve storage path: CLI flag > env > config-file > default XDG.
    // (T4 will replace the literal default with config-file resolution.)
    let storage_path = cmd.storage_path.clone().ok_or_else(|| {
        crate::cmd::exit::ExitKind::UserError.into_anyhow(
            "agentprof serve requires --storage-path (or AGENTPROF_STORAGE_PATH env / [storage] path config); \
             run `agentprof db init` then `agentprof db ingest` first".to_string(),
        )
    })?;
    if !storage_path.exists() {
        return Err(crate::cmd::exit::ExitKind::UserError.into_anyhow(format!(
            "storage path does not exist: {} — run `agentprof db init --storage-path <PATH>` first",
            storage_path.display(),
        )));
    }

    let db = agentprof_storage::Db::open(&storage_path).map_err(|e| {
        crate::cmd::exit::ExitKind::DataError
            .into_anyhow(format!("open SQLite store at {}: {e}", storage_path.display()))
    })?;

    let state = state::AppState {
        db: std::sync::Arc::new(std::sync::Mutex::new(db)),
        interval_default: cmd.interval_default,
    };

    // T5 will build the actual axum Router from `state` and bind / serve.
    // For now, prove the DB opens cleanly.
    tracing::info!(
        path = %storage_path.display(),
        interval_default = cmd.interval_default,
        "agentprof serve: store opened (T5 wires the listener)"
    );
    let _ = state;
    Ok(())
}
```

```rust
/// Merged `serve` runtime config — `ServeCmd` CLI args overlaid on top of
/// the `[serve]` config-file block, with built-in defaults filling holes.
#[derive(Debug, Clone)]
pub(super) struct ResolvedServeConfig {
    pub bind: std::net::SocketAddr,
    pub interval_default: u8,
    pub auto_open: bool,
}

/// Resolve a `ResolvedServeConfig` from the CLI args + an optional
/// config-file partial. CLI flags win; missing flags fall through to
/// the partial; missing-everywhere falls through to built-in defaults
/// (bind = 127.0.0.1:4329, interval_default = 5, auto_open = true).
///
/// # Errors
///
/// Returns `ExitKind::UserError` on:
/// - `--bind <ADDR>` parse failure (handled by clap; only relevant if
///   the config-file's bind string is malformed).
/// - `interval_default` out of range 1..=60.
pub(super) fn resolve_serve_config(
    cmd: &ServeCmd,
    file_partial: Option<&crate::config::PartialServeConfig>,
) -> anyhow::Result<ResolvedServeConfig> {
    let default_bind: std::net::SocketAddr = "127.0.0.1:4329".parse().expect("valid literal");

    // bind: CLI > file > default
    let bind = if let Some(b) = cmd.bind {
        b
    } else if let Some(fb) = file_partial.and_then(|p| p.bind.as_deref()) {
        fb.parse().map_err(|e| {
            crate::cmd::exit::ExitKind::UserError.into_anyhow(format!(
                "invalid [serve] bind: {fb:?}: {e}"
            ))
        })?
    } else {
        default_bind
    };

    // interval_default: CLI (always has value via clap default) wins;
    // file value used only when caller explicitly omits CLI (matchable via
    // cmd.interval_default == clap's default value, which is 5).
    let interval_default = if cmd.interval_default != 5 {
        cmd.interval_default
    } else if let Some(fi) = file_partial.and_then(|p| p.interval_default) {
        if !(1..=60).contains(&fi) {
            return Err(crate::cmd::exit::ExitKind::UserError.into_anyhow(format!(
                "[serve] interval_default out of range: {fi} (allowed 1..=60)"
            )));
        }
        fi
    } else {
        5
    };

    // auto_open: CLI's --no-open is a negative flag; if it's set, force false.
    // Otherwise the file's auto_open wins, defaulting to true.
    let auto_open = if cmd.no_open {
        false
    } else {
        file_partial.and_then(|p| p.auto_open).unwrap_or(true)
    };

    Ok(ResolvedServeConfig {
        bind,
        interval_default,
        auto_open,
    })
}
```

**Caveat on the `interval_default` priority logic**: clap fills `cmd.interval_default` with its `default_value = "5"` even when the user doesn't pass `--interval-default`. To distinguish "user said 5 explicitly" from "clap defaulted to 5", we'd need `Option<u8>` + manual default. Simplest correct fix: change the clap arg to `Option<u8>` and apply the default in `resolve_serve_config`:

OLD (in `ServeCmd`):
```rust
#[arg(long, value_name = "S", default_value = "5", value_parser = clap::value_parser!(u8).range(1..=60))]
pub interval_default: u8,
```

NEW:
```rust
#[arg(long, value_name = "S", value_parser = clap::value_parser!(u8).range(1..=60))]
pub interval_default: Option<u8>,
```

Then the resolve logic becomes cleaner:
```rust
let interval_default = cmd.interval_default
    .or_else(|| file_partial.and_then(|p| p.interval_default))
    .unwrap_or(5);
if !(1..=60).contains(&interval_default) {
    return Err(crate::cmd::exit::ExitKind::UserError.into_anyhow(format!(
        "interval_default out of range: {interval_default} (allowed 1..=60)"
    )));
}
```

Use this cleaner version. The clap `value_parser!(u8).range(1..=60)` still validates CLI-supplied values; the explicit check above guards file-supplied values.

Adjust the T2 CLI help test if needed (it doesn't assert on the default value).

```rust
pub fn run(cmd: ServeCmd) -> Result<()> {
    let rt = tokio::runtime::Builder::new_multi_thread()
        .enable_all()
        .build()
        .map_err(|e| {
            crate::cmd::exit::ExitKind::OutputError
                .into_anyhow(format!("build tokio runtime: {e}"))
        })?;
    rt.block_on(run_async(cmd))
}

async fn run_async(cmd: ServeCmd) -> Result<()> {
    // T4 config resolution
    let file_partial = crate::config::load_partial_from_disk()
        .ok()
        .and_then(|p| p.serve);
    let resolved = resolve_serve_config(&cmd, file_partial.as_ref())?;

    // T3 storage open
    let storage_path = cmd.storage_path.clone().ok_or_else(|| {
        crate::cmd::exit::ExitKind::UserError.into_anyhow(
            "agentprof serve requires --storage-path ...".to_string(),
        )
    })?;
    if !storage_path.exists() {
        return Err(crate::cmd::exit::ExitKind::UserError.into_anyhow(format!(
            "storage path does not exist: {}", storage_path.display()
        )));
    }
    let db = agentprof_storage::Db::open(&storage_path).map_err(|e| {
        crate::cmd::exit::ExitKind::DataError
            .into_anyhow(format!("open SQLite store at {}: {e}", storage_path.display()))
    })?;
    let state = state::AppState {
        db: std::sync::Arc::new(std::sync::Mutex::new(db)),
        interval_default: resolved.interval_default,
    };

    let app = router::build_router(state);

    // Bind warning for non-loopback
    if !resolved.bind.ip().is_loopback() {
        tracing::warn!(
            addr = %resolved.bind,
            "agentprof serve binding to non-loopback address — recommend reverse proxy for auth"
        );
    } else {
        tracing::info!(addr = %resolved.bind, "agentprof serve listening");
    }

    let listener = tokio::net::TcpListener::bind(resolved.bind).await.map_err(|e| {
        crate::cmd::exit::ExitKind::OutputError
            .into_anyhow(format!("bind {}: {e}", resolved.bind))
    })?;

    // Optional auto-open browser
    if resolved.auto_open {
        let url = format!("http://{}", resolved.bind);
        if let Err(e) = open::that(&url) {
            tracing::warn!(url = %url, error = %e, "failed to open browser (continuing)");
        }
    }

    axum::serve(listener, app)
        .with_graceful_shutdown(wait_for_shutdown())
        .await
        .map_err(|e| {
            crate::cmd::exit::ExitKind::OutputError
                .into_anyhow(format!("axum::serve: {e}"))
        })?;

    tracing::info!("agentprof serve stopped cleanly");
    Ok(())
}

#[cfg(unix)]
async fn wait_for_shutdown() {
    use tokio::signal::unix::{signal, SignalKind};
    let mut sigterm = signal(SignalKind::terminate()).expect("install SIGTERM handler");
    tokio::select! {
        _ = tokio::signal::ctrl_c() => tracing::info!("SIGINT received"),
        _ = sigterm.recv() => tracing::info!("SIGTERM received"),
    }
}

#[cfg(not(unix))]
async fn wait_for_shutdown() {
    let _ = tokio::signal::ctrl_c().await;
    tracing::info!("Ctrl-C received");
}
```

```rust
//! Compile-time-bundled dashboard static assets (M2.3 T6).
//!
//! CSS / JS / favicon are baked into the binary via `include_str!` /
//! `include_bytes!`. No filesystem reads at runtime; no external
//! CDN dependencies. Mirrors the same self-contained ethos as the
//! single-file HTML report (M1.6.4).

pub const CSS: &str = include_str!("../../../templates/dashboard/static/dashboard.css");
pub const JS: &str = include_str!("../../../templates/dashboard/static/dashboard.js");
pub const FAVICON_SVG: &[u8] = include_bytes!("../../../templates/dashboard/static/favicon.svg");

/// MIME-type lookup for a `/static/<name>` request. Returns
/// `None` for unknown asset names so the handler can return `404`.
#[must_use]
pub fn lookup(name: &str) -> Option<(&'static str, &'static [u8])> {
    match name {
        "dashboard.css" => Some(("text/css; charset=utf-8", CSS.as_bytes())),
        "dashboard.js" => Some(("application/javascript; charset=utf-8", JS.as_bytes())),
        "favicon.svg" => Some(("image/svg+xml", FAVICON_SVG)),
        _ => None,
    }
}
```

```rust
use askama::Template;

#[derive(Template)]
#[template(path = "dashboard/sessions.html")]
struct SessionsPage {
    active_nav: &'static str,
    interval_default: u8,
    version: &'static str,
    sessions: Vec<SessionRow>,
}

#[derive(Template)]
#[template(path = "dashboard/chunks/sessions.html")]
struct SessionsChunk {
    sessions: Vec<SessionRow>,
}

struct SessionRow {
    id: String,
    id_short: String,
    started_at_utc: String,
    model: String,
    turns: u32,
    out_tokens: u64,
    cache_pct_str: String,  // pre-formatted "82.7%" or empty
    duration: String,
    size_human: String,
}

fn load_sessions(state: &AppState) -> Vec<SessionRow> {
    let db = state.db.lock().unwrap_or_else(|p| p.into_inner());
    // Reuse the existing list-fetching code in cmd::list or directly query SqliteDataSource.
    // The exact API depends on agentprof-storage::SqliteDataSource — read the source
    // and use the canonical session-list query.
    let raw = agentprof_storage::SqliteDataSource::new(&*db)
        .list_sessions()  // method name placeholder — find actual name
        .unwrap_or_default();
    raw.into_iter().map(|s| SessionRow {
        id: s.id.clone(),
        id_short: s.id.chars().take(8).collect(),
        started_at_utc: s.started_at.to_rfc3339(),
        model: s.dominant_model.unwrap_or_else(|| "-".into()),
        turns: s.turn_count,
        out_tokens: s.total_output_tokens.unwrap_or(0) as u64,
        cache_pct_str: s.cache_metrics
            .map(|m| format!("{:.1}%", m.hit_rate_honest_pct))
            .unwrap_or_default(),
        duration: format_duration_ms(s.duration_ms),
        size_human: format_size_bytes(s.raw_size),
    }).collect()
}

pub async fn sessions_page(State(state): State<AppState>) -> impl IntoResponse {
    let tmpl = SessionsPage {
        active_nav: "sessions",
        interval_default: state.interval_default,
        version: env!("CARGO_PKG_VERSION"),
        sessions: load_sessions(&state),
    };
    match tmpl.render() {
        Ok(html) => (StatusCode::OK, [(header::CONTENT_TYPE, "text/html; charset=utf-8")], html).into_response(),
        Err(e) => {
            tracing::error!(error = %e, "sessions render");
            (StatusCode::INTERNAL_SERVER_ERROR, "render error").into_response()
        }
    }
}

pub async fn sessions_chunk(State(state): State<AppState>) -> impl IntoResponse {
    let tmpl = SessionsChunk { sessions: load_sessions(&state) };
    match tmpl.render() {
        Ok(html) => (StatusCode::OK, [
            (header::CONTENT_TYPE, "text/html; charset=utf-8"),
            (header::CACHE_CONTROL, "no-store"),
        ], html).into_response(),
        Err(e) => {
            tracing::error!(error = %e, "sessions chunk render");
            (StatusCode::INTERNAL_SERVER_ERROR, "render error").into_response()
        }
    }
}

// Helpers — copy from cmd::list (do NOT duplicate; extract into a shared format helper).
fn format_duration_ms(ms: Option<i64>) -> String {
    // mirror cmd::list::format_duration_ms; extract to a shared utility in a follow-up if duplication grows.
    ms.map(|m| {
        if m < 1000 { format!("{m}ms") }
        else if m < 60_000 { format!("{:.1}s", m as f64 / 1000.0) }
        else { format!("{:.1}m", m as f64 / 60_000.0) }
    }).unwrap_or_default()
}

fn format_size_bytes(bytes: Option<u64>) -> String {
    bytes.map(|b| {
        if b < 1024 { format!("{b}B") }
        else if b < 1024 * 1024 { format!("{:.1}k", b as f64 / 1024.0) }
        else { format!("{:.1}M", b as f64 / 1_048_576.0) }
    }).unwrap_or_default()
}
```

```javascript
// M2.3 dashboard polling + toolbar (full implementation).
(function() {
    'use strict';
    const main = document.getElementById('main');
    const status = document.getElementById('refresh-status');
    const pauseBtn = document.getElementById('btn-pause');
    const intervalSel = document.getElementById('sel-interval');
    if (!main || !status || !pauseBtn || !intervalSel) {
        console.warn('agentprof: missing UI elements; poller disabled');
        return;
    }

    let intervalSec = parseInt(
        localStorage.getItem('agentprof.interval')
        || document.body.dataset.intervalDefault
        || '5',
        10
    );
    let paused = localStorage.getItem('agentprof.paused') === '1';
    let timer = null;

    function setIntervalSelValue() { intervalSel.value = String(intervalSec); }
    function setPauseBtnText() { pauseBtn.textContent = paused ? '\u25b6 Resume' : '\u23f8 Pause'; }

    async function refresh() {
        if (paused) return;
        const apiPath = '/api' + window.location.pathname + '.html';
        try {
            const r = await fetch(apiPath + window.location.search, { headers: { 'Accept': 'text/html' } });
            if (r.ok) {
                main.innerHTML = await r.text();
                status.textContent = 'updated ' + new Date().toLocaleTimeString();
            } else {
                status.textContent = 'refresh failed: ' + r.status;
            }
        } catch (e) {
            status.textContent = 'refresh error: ' + e.message;
        }
    }

    function applyTimer() {
        if (timer) { clearInterval(timer); timer = null; }
        if (!paused && intervalSec > 0) {
            timer = setInterval(refresh, intervalSec * 1000);
        }
    }

    pauseBtn.addEventListener('click', () => {
        paused = !paused;
        localStorage.setItem('agentprof.paused', paused ? '1' : '0');
        setPauseBtnText();
        applyTimer();
        if (!paused) refresh();
    });
    intervalSel.addEventListener('change', (e) => {
        intervalSec = parseInt(e.target.value, 10);
        localStorage.setItem('agentprof.interval', String(intervalSec));
        applyTimer();
    });

    setIntervalSelValue();
    setPauseBtnText();
    applyTimer();
})();
```

Each test spawns `agentprof serve` as a real subprocess on an ephemeral port, probes over HTTP via reqwest, then sends Ctrl-C to shut down. Pattern mirrors M2.2 `tests/cli_ingest_otlp_e2e.rs`.

```rust
//! e2e tests for `agentprof serve` (M2.3).
//!
//! Each test spawns the binary in a child process bound to an ephemeral
//! port, then probes via reqwest. Mirrors M2.2's cli_ingest_otlp_e2e.rs.

#![cfg(feature = "web")]
#![allow(clippy::unwrap_used, clippy::expect_used)]

use std::net::{SocketAddr, TcpListener};
use std::process::{Child, Command, Stdio};
use std::time::{Duration, Instant};

use assert_cmd::cargo::cargo_bin;

fn ephemeral_addr() -> SocketAddr {
    let lis = TcpListener::bind("127.0.0.1:0").expect("bind");
    let a = lis.local_addr().expect("local_addr");
    drop(lis);
    a
}

fn wait_for_bind(addr: SocketAddr, deadline: Duration) -> bool {
    let start = Instant::now();
    while start.elapsed() < deadline {
        if std::net::TcpStream::connect_timeout(&addr, Duration::from_millis(100)).is_ok() {
            return true;
        }
        std::thread::sleep(Duration::from_millis(50));
    }
    false
}

struct ServerGuard {
    child: Child,
    addr: SocketAddr,
    _db_path: std::path::PathBuf,
}

impl Drop for ServerGuard {
    fn drop(&mut self) {
        // Use child.start_kill() (sends SIGKILL) — graceful SIGINT testing
        // is the job of e2e_serve_responds_to_sigint_within_grace_period.
        let _ = self.child.start_kill();
        let _ = self.child.wait();
    }
}

fn spawn_server(extra_args: &[&str]) -> ServerGuard {
    let addr = ephemeral_addr();
    let db_path = std::path::PathBuf::from(format!(
        "/tmp/agentprof-serve-e2e-{}-{}.db",
        std::process::id(),
        rand::random::<u32>()
    ));
    // Create an empty SQLite store first
    let _db = agentprof_storage::Db::open(&db_path).expect("open store");
    drop(_db);

    let mut cmd = Command::new(cargo_bin("agentprof"));
    cmd.args([
        "serve",
        "--bind", &addr.to_string(),
        "--storage-path", db_path.to_str().unwrap(),
        "--no-open",
        "--quiet",
    ]);
    cmd.args(extra_args);
    cmd.stdout(Stdio::null()).stderr(Stdio::null());
    let child = cmd.spawn().expect("spawn agentprof");
    assert!(wait_for_bind(addr, Duration::from_secs(5)), "serve didn't bind");
    ServerGuard { child, addr, _db_path: db_path }
}

#[tokio::test(flavor = "multi_thread")]
async fn e2e_serve_binds_and_serves_healthz() {
    let server = spawn_server(&[]);
    let resp = reqwest::get(&format!("http://{}/healthz", server.addr)).await.expect("get");
    assert_eq!(resp.status(), 200);
    let body = resp.text().await.expect("body");
    assert_eq!(body, "healthy");
}

#[tokio::test]
async fn e2e_serve_with_missing_storage_path_exits_user_error() {
    use assert_cmd::Command as ACommand;
    ACommand::cargo_bin("agentprof").expect("cargo_bin")
        .args(["serve", "--bind", "127.0.0.1:0", "--no-open", "--quiet"])
        .assert()
        .failure()
        .code(1);  // ExitKind::UserError
}

async fn e2e_serve_with_nonexistent_storage_path_exits_user_error() {
    use assert_cmd::Command as ACommand;
    ACommand::cargo_bin("agentprof").expect("cargo_bin")
        .args(["serve", "--bind", "127.0.0.1:0", "--storage-path", "/nonexistent/path.db", "--no-open", "--quiet"])
        .assert()
        .failure()
        .code(1);  // ExitKind::UserError
}

#[tokio::test(flavor = "multi_thread")]
async fn e2e_serve_serves_sessions_page() {
    let server = spawn_server(&[]);
    let resp = reqwest::get(&format!("http://{}/sessions", server.addr)).await.expect("get");
    assert_eq!(resp.status(), 200);
```
