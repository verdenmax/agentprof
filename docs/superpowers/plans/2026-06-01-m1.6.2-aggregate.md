# M1.6.2 — `agentprof aggregate` subcommand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `agentprof aggregate --by tool|mcp-server|day|model --since N --export md|json|csv|html [--output FILE] [--low-utilization-threshold N]` for cross-session aggregation reports.

**Architecture:** Pure aggregator functions live in `agentprof-core::analyzer::aggregate::{group_by_tool,group_by_mcp_server,group_by_day,group_by_model}` (lib, type-safe per-bucket via generic `AggregateReport<B>`). CLI `cmd::aggregate` loads N sessions sequentially (reuses `list`'s per-session pipeline), wraps the result in `AnyAggregateReport` enum at the serde boundary, then dispatches to 4 thin renderer modules (`format::aggregate_{md,json,csv,html}`). HTML re-uses M1.6.4's askama 0.16 machinery (new `aggregate.html` template). TUI export deferred to M1.6.3.

**Tech Stack:** Rust 2021 (MSRV 1.78); serde + serde_json for JSON; chrono `NaiveDate` for UTC day buckets; askama 0.16 for HTML; **new dep `csv = "1"`** for CSV exporter; insta for snapshot tests; assert_cmd + predicates for CLI integration.

**Spec:** [`docs/superpowers/specs/2026-06-01-m1.6.2-aggregate-design.md`](../specs/2026-06-01-m1.6.2-aggregate-design.md) (commit `a006da6`)

/// ```

///     by: AggregateKey::Tool,
///     since: Duration::days(30),
///     session_count: 0,
///     failure_count: 0,
///     total_wall_duration: Duration::zero(),
///     buckets: Vec::new(),
/// };
/// assert_eq!(r.session_count, 0);
/// ```
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[non_exhaustive]
pub struct AggregateReport<B> {
    /// Which key this report was aggregated by.
    pub by: AggregateKey,
    /// Time window upper bound resolved from `--since`.
    #[serde(with = "duration_seconds")]
    pub since: Duration,
    /// Number of sessions actually included.
    pub session_count: usize,
    /// Number of sessions skipped due to parse error.
    pub failure_count: usize,
    /// Sum of all included session wall-clock durations.
    #[serde(with = "duration_seconds")]
    pub total_wall_duration: Duration,
    /// Per-bucket rows, type-safe per B. Sorted per the key's natural metric.
    pub buckets: Vec<B>,
}

- [ ] **Step 1.10: Fill in `group_by_tool.rs`**

Replace the stub `aggregate_by_tool` body. The algorithm:

1. Use `BTreeMap<(String, ToolSource), TempBucket>` keyed by (name, source) so identical-named tools from different sources don't collide.
2. For each `(report, episodes)`:
   - For each `ToolRankRow row` in `report.tool_rank`:
     - upsert by (row.name, row.source)
     - accumulate: call_count, success_count, failure_count, total_duration; increment session_count by 1 (this session used the tool); add all per-call durations from `episodes.tools[&row.name].calls[*].span.duration()` into a pool
3. After all reports processed:
   - For each bucket: re-compute p50/p95 from the pooled durations via `percentile()` helper (see below).
4. Convert temp buckets into ToolBucket vec
5. Sort by `total_duration` desc
6. Set `total_wall_duration` = sum of (last_event_time - meta.started_at) across reports — but how? We need episodes for per-session wall duration. Use `episodes_per_report[i]` to compute wall:
   - wall_i = max event time across episodes - meta.started_at; if no events, 0
7. Return AggregateReport

Implementation:

```rust
use std::collections::BTreeMap;

use chrono::{DateTime, Utc};

use crate::analyzer::aggregate::{AggregateKey, AggregateReport, ToolBucket};
use crate::analyzer::AnalysisReport;
use crate::episode::Episodes;
use crate::model::ToolSource;

#[must_use]
pub fn aggregate_by_tool(
    reports: &[AnalysisReport],
    episodes_per_report: &[Episodes],
) -> AggregateReport<ToolBucket> {
    assert_eq!(
        reports.len(),
        episodes_per_report.len(),
        "aggregate_by_tool: reports and episodes_per_report length mismatch"
    );

    let mut acc: BTreeMap<(String, ToolSource), TempToolAcc> = BTreeMap::new();
    let mut total_wall = chrono::Duration::zero();

    for (report, episodes) in reports.iter().zip(episodes_per_report.iter()) {
        total_wall = total_wall + compute_wall(episodes, report.meta.started_at);

        for row in &report.tool_rank {
            let key = (row.name.clone(), row.source.clone());
            let entry = acc.entry(key).or_default();
            entry.name = row.name.clone();
            entry.source = row.source.clone();
            entry.call_count += row.call_count;
            entry.success_count += row.success_count;
            entry.failure_count += row.failure_count;
            entry.total_duration = entry.total_duration + row.total_duration;
            entry.session_count += 1;

            if let Some(tool) = episodes.tools.get(&row.name) {
                for call in &tool.calls {
                    let d = call.span.ended_at - call.span.started_at;
                    if d >= chrono::Duration::zero() {
                        entry.duration_pool.push(d);
                    }
                }
            }
        }
    }

    let mut buckets: Vec<ToolBucket> = acc
        .into_values()
        .map(|t| {
            let mut pool = t.duration_pool;
            pool.sort_unstable();
            ToolBucket {
                name: t.name,
                source: t.source,
                call_count: t.call_count,
                success_count: t.success_count,
                failure_count: t.failure_count,
                total_duration: t.total_duration,
                p50_duration: percentile(&pool, 0.50),
                p95_duration: percentile(&pool, 0.95),
                session_count: t.session_count,
            }
        })
        .collect();

    buckets.sort_by(|a, b| b.total_duration.cmp(&a.total_duration));

    AggregateReport {
        by: AggregateKey::Tool,
        since: chrono::Duration::zero(),  // CLI overwrites
        session_count: reports.len(),
        failure_count: 0,                  // CLI overwrites
        total_wall_duration: total_wall,
        buckets,
    }
}

#[derive(Default)]
struct TempToolAcc {
    name: String,
    source: ToolSource,
    call_count: usize,
    success_count: usize,
    failure_count: usize,
    total_duration: chrono::Duration,
    session_count: usize,
    duration_pool: Vec<chrono::Duration>,
}

fn percentile(sorted_pool: &[chrono::Duration], p: f64) -> chrono::Duration {
    if sorted_pool.is_empty() {
        return chrono::Duration::zero();
    }
    let idx = ((sorted_pool.len() as f64) * p).floor() as usize;
    let idx = idx.min(sorted_pool.len().saturating_sub(1));
    sorted_pool[idx]
}

fn compute_wall(episodes: &Episodes, session_start: DateTime<Utc>) -> chrono::Duration {
    let mut latest = session_start;
    for turn in &episodes.turns {
        if let Some(end) = turn.ended_at {
            if end > latest { latest = end; }
        }
    }
    for tool in episodes.tools.values() {
        for call in &tool.calls {
            if call.span.ended_at > latest { latest = call.span.ended_at; }
        }
    }
    let d = latest - session_start;
    if d < chrono::Duration::zero() { chrono::Duration::zero() } else { d }
}

            .turn_summary
            .iter()
            .filter_map(|t| t.output_tokens)
            .map(u64::from)
            .sum();

        total_wall = total_wall + wall;

        let entry = acc.entry(date).or_default();
        entry.date = date;
        entry.session_count += 1;
        entry.total_wall_duration = entry.total_wall_duration + wall;
        entry.total_tool_duration = entry.total_tool_duration + tool_time;
        entry.total_output_tokens += out_tokens;
    }

    let buckets: Vec<DayBucket> = acc
        .into_values()
        .map(|t| {
            let wall_ms = t.total_wall_duration.num_milliseconds();
            let tool_ms = t.total_tool_duration.num_milliseconds();
            let util = if wall_ms > 0 {
                ((tool_ms as f64) * 100.0 / (wall_ms as f64)) as f32
            } else {
                0.0
            };
            let util = util.clamp(0.0, 100.0);
            DayBucket {
                date: t.date,
                session_count: t.session_count,
                total_wall_duration: t.total_wall_duration,
                total_tool_duration: t.total_tool_duration,
                total_output_tokens: t.total_output_tokens,
                utilization_pct: util,
                is_low_utilization: util < low_util_threshold_pct,
            }
        })
        .collect();
    // BTreeMap iteration is already date-ascending; no extra sort needed.

    AggregateReport {
        by: AggregateKey::Day,
        since: chrono::Duration::zero(),
        session_count: reports.len(),
        failure_count: 0,
        total_wall_duration: total_wall,
        buckets,
    }
}

#[derive(Default)]
struct TempDayAcc {
    date: NaiveDate,
    session_count: usize,
    total_wall_duration: chrono::Duration,
    total_tool_duration: chrono::Duration,
    total_output_tokens: u64,
}

fn compute_wall(episodes: &Episodes, session_start: chrono::DateTime<chrono::Utc>) -> chrono::Duration {
    let mut latest = session_start;
    for turn in &episodes.turns {
        if let Some(end) = turn.ended_at { if end > latest { latest = end; } }
    }
    for tool in episodes.tools.values() {
        for call in &tool.calls { if call.span.ended_at > latest { latest = call.span.ended_at; } }
    }
    let d = latest - session_start;
    if d < chrono::Duration::zero() { chrono::Duration::zero() } else { d }
}

fn sum_tool_duration(episodes: &Episodes) -> chrono::Duration {
    let mut total = chrono::Duration::zero();
    for tool in episodes.tools.values() {
        for call in &tool.calls {
            let d = call.span.ended_at - call.span.started_at;
            if d >= chrono::Duration::zero() { total = total + d; }
        }
    }
    total
}

//! `agentprof aggregate` subcommand (M1.6.2).
//!
//! Discovers sessions under `--root` (or the adapter default),
//! filters by `--since`, parses sequentially (D-2 — rayon deferred),
//! computes the requested cross-session aggregate, and renders to
//! md / json / csv / html.

use std::io::Write;
use std::path::PathBuf;
use std::str::FromStr;
use std::time::SystemTime;

use anyhow::{Context as _, Result};
use clap::{Args, ValueEnum};

use agentprof_adapters::copilot::CopilotAdapter;
use agentprof_adapters::registry;
use agentprof_core::adapter::{Adapter, AgentKind, SessionMeta, SessionRef};
use agentprof_core::analyzer::aggregate::{
    group_by_day::aggregate_by_day,
    group_by_mcp::aggregate_by_mcp_server,
    group_by_model::aggregate_by_model,
    group_by_tool::aggregate_by_tool,
    AggregateKey, AnyAggregateReport,
};
use agentprof_core::analyzer::{analyze, AnalysisReport};
use agentprof_core::episode::{derive_episodes, Episodes};

use crate::cmd::analyze::ExitKind;
use crate::cmd::format;

/// Arguments for `agentprof aggregate`.
#[derive(Args, Debug, Clone)]
#[non_exhaustive]
pub struct AggregateCmd {
    /// Agent whose sessions to aggregate. M1.6.2 supports only `copilot`.
    #[arg(long, value_enum, default_value_t = AgentKind::Copilot)]
    pub agent: AgentKind,

    /// Override the adapter's default session-state root.
    #[arg(long)]
    pub root: Option<PathBuf>,

    /// Group-by key. Required.
    #[arg(long, value_enum)]
    pub by: AggregateKey,

    /// Time window: `<N>d`, `<N>h`, `<N>m`, `<N>s`, or `all`. Default `30d`.
    #[arg(long, default_value = "30d")]
    pub since: String,

    /// Maximum bucket rows in the final report. `0` = unlimited.
    #[arg(long, default_value_t = 0)]
    pub limit: usize,

    /// Output format.
    #[arg(long, value_enum, default_value_t = AggExportFormat::Md)]
    pub export: AggExportFormat,

    /// Write to file instead of stdout.
    #[arg(long)]
    pub output: Option<PathBuf>,

    /// Percentage threshold below which `--by day` rows are marked low-utilization.
    /// Range 0.0 to 100.0. Default 20.
    #[arg(long, default_value_t = 20.0)]
    pub low_utilization_threshold: f32,
}

/// Output format for aggregate (subset of analyze's; no TUI in M1.6.2).
#[derive(ValueEnum, Debug, Clone, Copy, PartialEq)]
pub enum AggExportFormat {
    /// Markdown to stdout/file (default).
    Md,
    /// JSON of `AnyAggregateReport`.
    Json,
    /// CSV with header row, one row per bucket.
    Csv,
    /// Self-contained static HTML (no JS, askama-templated).
    Html,
}

/// Entry point. Wraps the inner pipeline so we can flush + propagate errors.
///
/// # Errors
///
/// Returns `ExitKind::UserError` for invalid args / nonexistent root,
/// `ExitKind::DataError` if every discovered session fails to parse,
/// `ExitKind::OutputError` for I/O failures.
pub fn run(cmd: AggregateCmd) -> Result<()> {
    // Validate threshold range.
    if !(0.0..=100.0).contains(&cmd.low_utilization_threshold) {
        return Err(ExitKind::UserError.into_anyhow(format!(
            "--low-utilization-threshold must be between 0.0 and 100.0; got {}",
            cmd.low_utilization_threshold
        )));
    }

    // Resolve adapter.
    let adapter = match cmd.agent {
        AgentKind::Copilot => CopilotAdapter::default(),
        _ => {
            return Err(ExitKind::UserError.into_anyhow(format!(
                "agent {:?} is not yet supported by `agentprof aggregate`; only copilot",
                cmd.agent
            )));
        }
    };

    // Resolve root.
    let root = cmd
        .root
        .clone()
        .or_else(|| adapter.default_session_root())
        .ok_or_else(|| ExitKind::UserError.into_anyhow(
            "could not determine session root; pass --root explicitly".to_string()
        ))?;

    if !root.is_dir() {
        return Err(ExitKind::UserError.into_anyhow(format!(
            "session root not found: {}", root.display()
        )));
    }

    // Parse --since.
    let since_dur = parse_since(&cmd.since)
        .map_err(|msg| ExitKind::UserError.into_anyhow(format!("--since: {msg}")))?;

    // Discover + filter.
    let all_refs = CopilotAdapter::discover_sessions(&root)
        .map_err(|e| ExitKind::DataError.into_anyhow(format!("discover sessions: {e}")))?;
    let cutoff = SystemTime::now() - since_dur;
    let refs: Vec<SessionRef> = all_refs
        .into_iter()
        .filter(|sref| sref.modified_at >= cutoff)
        .collect();

    if refs.is_empty() {
        eprintln!(
            "agentprof: no sessions matching --since={} under {}",
            cmd.since, root.display()
        );
        return Ok(());
    }

    // Sequential parse (per D-2).
    let mut reports: Vec<AnalysisReport> = Vec::with_capacity(refs.len());
    let mut episodes_vec: Vec<Episodes> = Vec::with_capacity(refs.len());
    let mut metas: Vec<SessionMeta> = Vec::with_capacity(refs.len());
    let mut failure_count = 0;

    for sref in &refs {
        match load_and_analyze(&adapter, sref) {
            Ok((report, episodes, meta)) => {
                reports.push(report);
                episodes_vec.push(episodes);
                metas.push(meta);
            }
            Err(e) => {
                eprintln!(
                    "agentprof: warning: failed to parse session {}: {e:#}",
                    sref.id
                );
                failure_count += 1;
            }
        }
    }

    if reports.is_empty() && failure_count > 0 {
        eprintln!(
            "agentprof: all {} sessions failed to parse; nothing to aggregate",
            failure_count
        );
        return Err(ExitKind::DataError.into_anyhow(format!(
            "all {failure_count} sessions failed to parse"
        )));
    }

    // Build the AnyAggregateReport based on --by.
    let mut any_report = match cmd.by {
        AggregateKey::Tool => {
            AnyAggregateReport::Tool(aggregate_by_tool(&reports, &episodes_vec))
        }
        AggregateKey::McpServer => {
            AnyAggregateReport::McpServer(aggregate_by_mcp_server(&reports, &episodes_vec))
        }
        AggregateKey::Day => {
            AnyAggregateReport::Day(aggregate_by_day(
                &reports, &episodes_vec, cmd.low_utilization_threshold,
            ))
        }
        AggregateKey::Model => {
            AnyAggregateReport::Model(aggregate_by_model(&reports, &episodes_vec))
        }
    };

    // Fill in since + failure_count (aggregators don't know these).
    fill_metadata(&mut any_report, since_dur_chrono(&since_dur), failure_count);

    // Apply --limit.
    if cmd.limit > 0 {
        truncate_buckets(&mut any_report, cmd.limit);
    }

    // Render.
    let output = match cmd.export {
        AggExportFormat::Md => format::aggregate_md::render(&any_report),
        AggExportFormat::Json => serde_json::to_string_pretty(&any_report)
            .context("serialize AnyAggregateReport to JSON")?,
        AggExportFormat::Csv => format::aggregate_csv::render(&any_report)
            .context("render aggregate CSV")?,
        AggExportFormat::Html => format::aggregate_html::render(
            &any_report, cmd.low_utilization_threshold, env!("CARGO_PKG_VERSION"),
        ),
    };

    // Write.
    if let Some(path) = &cmd.output {
        std::fs::write(path, output)
            .map_err(|e| ExitKind::OutputError.into_anyhow(format!(
                "write {}: {e}", path.display()
            )))?;
    } else {
        let stdout = std::io::stdout();
        let mut handle = stdout.lock();
        handle.write_all(output.as_bytes())
            .map_err(|e| ExitKind::OutputError.into_anyhow(format!("stdout: {e}")))?;
        // Ensure trailing newline so terminal output looks clean.
        if !output.ends_with('\n') { handle.write_all(b"\n").ok(); }
    }

    // Trailing stderr summary if any failures.
    if failure_count > 0 {
        let total = reports.len() + failure_count;
        eprintln!(
            "agentprof: aggregated {} of {} sessions ({} failed)",
            reports.len(), total, failure_count
        );
    }

    Ok(())
}

/// Load + analyze a single session. Returns (report, episodes, meta).
fn load_and_analyze(
    adapter: &CopilotAdapter,
    sref: &SessionRef,
) -> Result<(AnalysisReport, Episodes, SessionMeta)> {
    let raw = adapter.load_session(sref)?;
    let episodes = derive_episodes(&raw.events, &raw.meta);
    let report = analyze(&episodes, &raw.meta, &raw.parse_warnings);
    Ok((report, episodes, raw.meta))
}

/// Parse `<N>{d|h|m|s}` or `all`. Returns std::time::Duration.
fn parse_since(s: &str) -> Result<std::time::Duration, String> {
    if s == "all" {
        return Ok(std::time::Duration::MAX);
    }
    if s.len() < 2 {
        return Err(format!("expected <N>{{d|h|m|s}} or `all`; got `{s}`"));
    }
    let (n_str, unit) = s.split_at(s.len() - 1);
    let n: u64 = n_str.parse()
        .map_err(|_| format!("invalid number `{n_str}` in --since {s}"))?;
    let secs = match unit {
        "d" => n * 86_400,
        "h" => n * 3_600,
        "m" => n * 60,
        "s" => n,
        _ => return Err(format!("unknown unit `{unit}` in --since {s}")),
    };
    Ok(std::time::Duration::from_secs(secs))
}

fn since_dur_chrono(d: &std::time::Duration) -> chrono::Duration {
    let secs = i64::try_from(d.as_secs()).unwrap_or(i64::MAX);
    chrono::Duration::seconds(secs)
}

fn fill_metadata(r: &mut AnyAggregateReport, since: chrono::Duration, failure_count: usize) {

        AnyAggregateReport::Model(x)     => { x.since = since; x.failure_count = failure_count; }
    }
}

        AnyAggregateReport::McpServer(x) => ("mcp-server", x.session_count, x.failure_count, x.since, x.total_wall_duration),
        AnyAggregateReport::Day(x)       => ("day",        x.session_count, x.failure_count, x.since, x.total_wall_duration),
        AnyAggregateReport::Model(x)     => ("model",      x.session_count, x.failure_count, x.since, x.total_wall_duration),
    }
}

fn human_duration(d: chrono::Duration) -> String {
    let ms = d.num_milliseconds();
    if ms == 0 { return "0 ms".to_string(); }
    if ms < 1000 { return format!("{ms} ms"); }
    if ms < 60_000 { return format!("{:.1} s", ms as f64 / 1000.0); }
    if ms < 3_600_000 { return format!("{:.1} min", ms as f64 / 60_000.0); }
    format!("{:.1} h", ms as f64 / 3_600_000.0)
}

fn html_escape(s: &str) -> String {
    s.replace('&', "&amp;").replace('<', "&lt;").replace('>', "&gt;")
        .replace('"', "&quot;").replace('\'', "&#39;")
}

- [ ] **Step 3.1: Write ADR-0008**

Create `docs/internals/adr-0008-aggregate-report-and-utilization.md`:

```markdown
# ADR-0008 — AggregateReport<B> + utilization metric

> **Status:** Accepted
> **Date:** 2026-06-01
> **Deciders:** agentprof team
> **Supersedes:** —
> **Spec:** [`2026-06-01-m1.6.2-aggregate-design.md`](../superpowers/specs/2026-06-01-m1.6.2-aggregate-design.md)
> **Plan:** [`2026-06-01-m1.6.2-aggregate.md`](../superpowers/plans/2026-06-01-m1.6.2-aggregate.md)

## Context

M1.6.2 ships the `agentprof aggregate` subcommand: 4 `--by` keys
(tool / mcp-server / day / model) × 4 `--export` formats
(md / json / csv / html). This ADR documents two cross-cutting design
decisions: the type-safe wrapper around heterogeneous bucket data, and
the meaning of "utilization" for the day key.

## Decision

### D-7: Generic `AggregateReport<B>` + outer `AnyAggregateReport` enum

The aggregate report carries the same metadata regardless of key
(session_count, total_wall_duration, since, etc.) but different bucket
data per key. Three patterns were considered:

| Pattern | Trade-off |
|---|---|
| Single `AggregateReport` struct with 4 `Vec<X>` fields (3 always empty) | Simple serde; CLI dispatch trivial; but 3 wasted Vec allocations + confusing API surface |
| Generic `AggregateReport<B>` returned from each aggregator | Type-safe per bucket; zero wasted allocation; but serde + CLI need a wrapper at runtime |
| Trait object `Box<dyn Bucket>` | Most flexible; but Serialize-on-trait-objects is non-trivial and CLI dispatch needs downcasts |

**Chosen: pattern 2** (per user preference D-7). The CLI/serde
boundary wraps `AggregateReport<X>` in an `AnyAggregateReport` enum.
Internal pipelines use the concrete generic type directly; only the
CLI dispatcher and renderers cross the enum boundary.

```rust
pub struct AggregateReport<B> { /* metadata + Vec<B> */ }

#[serde(tag = "by", content = "data", rename_all = "snake_case")]
pub enum AnyAggregateReport {
    Tool(AggregateReport<ToolBucket>),
    McpServer(AggregateReport<McpServerBucket>),
    Day(AggregateReport<DayBucket>),
    Model(AggregateReport<ModelBucket>),
}
```

### D-12: Session model = first-turn model

A single session may switch models mid-run. Representing this in the
aggregate report cleanly requires either:
- One bucket per model per session (complex; non-trivial schema), or
- A single representative model per session (simple; loses precision)

We chose the **representative-value approach**: the model active at
the FIRST turn of a session is the session's model. This is
intentionally lossy for the small minority of multi-model sessions
in exchange for a clear schema and trivial implementation. Sessions
where `report.turn_summary[0].model` is `None` are excluded from the
model aggregation (rare; happens when a session has no turns or no
recorded model).

Future work (deferred): multi-model attribution via `mode_segments`
where each (model, span) pair contributes to a bucket weighted by
its duration share.

### D-5 / D-6: `--by day` adds a `utilization_pct` field with auto warn flag

For the `day` key, each day-bucket carries:
- `total_wall_duration` — sum of session wall-clock durations
- `total_tool_duration` — sum of all tool call durations
- `utilization_pct = total_tool_duration / total_wall_duration × 100`
- `is_low_utilization` = `utilization_pct < low_threshold` (caller-supplied)

The CLI accepts `--low-utilization-threshold 0-100` (default 20). The
threshold parameter is plumbed all the way to the aggregator (not just
the renderer) because `is_low_utilization` is data, not presentation —
the JSON / CSV serializers carry it too.

**Why this metric is interesting**:
- Low utilization (e.g. < 20%) suggests the agent is mostly thinking/
  waiting and tools are rare. Often a sign of "too many MCP servers
  loaded in context but few actually called."
- High utilization (e.g. > 50%) suggests tools dominate the time
  budget. Often the healthy case.
- Trend over time helps spot regressions: "agent dropped from 30% to
  15% utilization in May after I added MCP server X" → suggests X
  is contributing to slow LLM thinking.

### D-2: Sequential parsing for MVP (not rayon)

Cross-session aggregation requires loading and parsing N sessions.
rayon would offer 4-8× parallelism for I/O-bound parsing but adds
a dep + complicates failure tracking + complicates ordering. Per user
preference, MVP ships sequential; rayon deferred to a future perf
milestone.

For typical workloads (100 sessions × ~100 ms = 10s), sequential is
acceptable. Larger workloads (1000+ sessions) will motivate the perf
milestone.

### D-15 (referenced from spec): Span overlap handling

Aggregation does NOT re-handle span overlap — it inherits whatever
`Episodes` reports from the derive layer. Per-call durations entering
the percentile pool are clamped to `>= 0` (a `compute_wall` invariant);
no `ExportWarning` is emitted (those are emitted by Speedscope export,
not by aggregate).

### D-9: UTC dates for day bucket

`day` bucket uses `chrono::NaiveDate` derived from `meta.started_at`
via `.date_naive()`. This is UTC because events.jsonl timestamps are
RFC3339 UTC; no system timezone introduced. Documented in cli README
+ this ADR. Future flag `--timezone <IANA>` is a non-MVP extension.

### Percentile recomputation (NOT averaging)

Per-session `ToolRankRow.p50_duration` is the 50th percentile across
that session's calls. The aggregate p50 is NOT `avg(per-session p50)`
— that's statistically wrong. The aggregator pools ALL per-call
durations across all sessions, sorts, then takes the nominal index.

This requires the aggregator to take `&[Episodes]` alongside
`&[AnalysisReport]` (the report alone doesn't carry per-call durations).

## Consequences

- The `AggregateReport<B>` design adds a small amount of generic-Rust
  ceremony (constructors, trait bounds) in exchange for type safety.
- `AnyAggregateReport` is `#[serde(tag = "by", content = "data")]` —
  external JSON consumers get a self-describing payload:
  `{"by": "tool", "data": { ... }}`.
- The CLI dispatcher (in `cmd::aggregate::run`) has 4 match arms (one
  per key) that produce concrete `AggregateReport<X>` instances; each
  is wrapped in the matching `AnyAggregateReport` variant before
  rendering.
- Renderers (md / json / csv / html) each have a single entry point
  that takes `&AnyAggregateReport` and dispatches on the inner enum.
- Per-session parse failures degrade gracefully (counted, surfaced to
  stderr); all-fail exits `DataError(2)`. Empty-window exits 0 with
  a stderr message.
- The utilization metric is computed at aggregation time (not lazily
  in the renderer) so JSON / CSV consumers can sort/filter on it.
- TUI export is deferred to M1.6.3 alongside the `watch` subcommand;
  `--export tui` is not a variant in `AggExportFormat` and clap
  rejects it with the standard "invalid value" error.

## Implementation

- Module: `agentprof-core::analyzer::aggregate` (lib, ~800 LOC)
  - `mod.rs` — `AggregateKey`, `AggregateReport<B>`, `AnyAggregateReport`
  - `bucket.rs` — 4 bucket types
  - `group_by_{tool,mcp,day,model}.rs` — 4 pure aggregator functions
- CLI: `agentprof-cli::cmd::aggregate::run` (~280 LOC orchestrator)
- Renderers: 3 modules in `cmd/format/aggregate_{md,csv,html}.rs`;
  JSON inlined in dispatcher
- Template: `crates/agentprof-cli/templates/aggregate.html` (askama 0.16,
  reuses M1.6.4's `styles.css` with new `.warn-row` class)
- Fixtures: 3 new `multi-sess-{a,b,c}` synthetic sessions covering
  multi-day / multi-model / multi-tool / MCP / skill / failure cases
- Tests: 10 core unit (`crates/agentprof-core/tests/aggregate.rs`) +
  10 cli (7 integration + 3 snapshot) = 20 new tests
- New dep: `csv = "1"` (workspace); `Unlicense` may need addition to
  `deny.toml` license allowlist depending on csv's transitive deps
