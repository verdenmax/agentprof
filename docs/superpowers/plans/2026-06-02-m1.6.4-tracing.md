# M1.6.4 — Tracing infrastructure (structured observability) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `tracing` the canonical observability channel across all five crates: add a `core::observability::pii::hash_path` helper, a `cli::observability::{config,init,tui_guard}` initialization module, global `--log-level` / `--log-file` CLI flags, and a TUI-aware writer that auto-redirects to `$XDG_STATE_HOME/agentprof/agentprof.log` (rolling daily). Convert all 14 production `eprintln!` call sites to `tracing::{warn,info,error}!` and add `#[tracing::instrument]` on 13 key entry points across cli, adapters, and core, so every emission carries `cmd.* / adapter.* / analyzer.* / aggregator.*` span context with PII-hashed session paths.

**Architecture:** Two new modules — `agentprof-core::observability::pii` (leaf-lib helper; only depends on `sha2`) and `agentprof-cli::observability::{config,init,tui_guard}` (orchestrator-only; depends on `tracing-appender` for non-blocking rolling-file writes). `LogConfig::resolve(&Cli)` merges flags > env > defaults into a frozen config; `init_tracing(&cfg)` installs a subscriber + returns a `TracingHandle` holding the appender's `WorkerGuard` for the process lifetime. TUI subcommands wrap their `enter`/`leave` in an RAII `enter_tui_log_guard` that auto-switches the writer to the XDG log file and prints the path on Drop. All init failures soft-fall to default stderr — tracing never blocks CLI startup. Span topology is 4 layers deep: `cmd.{analyze,list,aggregate,watch}` → `adapter.{discover,parse,load_meta}` → `analyzer.{derive_episodes,analyze}` + `aggregator.group_by_*` → events. Session paths are emitted as `session = %hash` via the new `pii::hash_path()` helper (sha256[..8] hex).

**Tech Stack:** Rust 2021 (MSRV 1.78); existing `tracing = "0.1"` + `tracing-subscriber = "0.3"` (feature `env-filter` already on); new direct workspace deps `sha2 = "0.10"` (core only; MIT OR Apache-2.0) + `tracing-appender = "0.2"` (cli only; MIT). Both license-allowlisted via existing `deny.toml`; no `deny.toml` change required.

**Spec:** [`docs/superpowers/specs/2026-06-02-tracing-design.md`](../specs/2026-06-02-tracing-design.md) (commit `7573a81`)

**ADR:** [`docs/internals/adr-0010-tracing-infrastructure.md`](../../internals/adr-0010-tracing-infrastructure.md) (commit `1c10016`)

//! PII redaction helpers for tracing emissions.
//!
//! See [`hash_path`] for the canonical "short hash a session path"
//! function; emit it via `tracing::info_span!("cmd.analyze", session = %hash_path(p))`
//! and consumers can group / correlate without seeing the raw filesystem path.

use sha2::{Digest, Sha256};
use std::path::Path;

/// Stable 8-character lowercase hex prefix of SHA-256 of the path's
/// byte representation (lossy-converted to UTF-8 to tolerate non-UTF-8
/// paths). Deterministic across runs and across operating systems.
///
/// # PII trade-off
///
/// 8 hex chars = 32 bits. Birthday-bound collision probability ≈ 50 %
/// at √(2³²) ≈ 65 536 distinct paths. For a developer tool that
/// typically processes < 1 000 sessions per run this is fine; if you
/// observe a collision in support traces, set
/// `AGENTPROF_LOG_FULL_PATHS=1` to emit raw paths and re-run.
///
/// # Examples
///
/// ```
/// use agentprof_core::observability::pii::hash_path;
/// use std::path::PathBuf;
///
/// let h1 = hash_path(&PathBuf::from("/home/alice/.cache/x"));
/// let h2 = hash_path(&PathBuf::from("/home/alice/.cache/x"));
/// assert_eq!(h1, h2);
/// assert_eq!(h1.len(), 8);
/// ```
pub fn hash_path(p: &Path) -> String {
    hash_short(&p.to_string_lossy())
}

/// Stable 8-character lowercase hex prefix of SHA-256(input bytes).
/// Same collision trade-off as [`hash_path`].
///
/// # Examples
///
/// ```
/// use agentprof_core::observability::pii::hash_short;
///
/// let h = hash_short("abc");
/// assert_eq!(h.len(), 8);
/// assert!(h.chars().all(|c| c.is_ascii_hexdigit()));
/// ```
pub fn hash_short(s: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(s.as_bytes());
    let digest = hasher.finalize();
    // 4 bytes = 8 hex chars.
    let mut out = String::with_capacity(8);
    for b in &digest[..4] {
        use std::fmt::Write;
        let _ = write!(&mut out, "{b:02x}");
    }
    out
}

//!
//! Construct via [`LogConfig::resolve`] from a parsed `&Cli`; pass the
//! resulting config into [`super::init_tracing`]. Resolution NEVER fails
//! and never returns a Result — invalid inputs soft-fall to the default

use std::path::PathBuf;

/// Where tracing events are written.
#[derive(Debug, Clone)]
#[non_exhaustive]
pub enum LogWriter {
    /// Default writer. Used unless `--log-file <PATH>` or
    /// `AGENTPROF_LOG_FILE=<PATH>` is set, OR the special value `-` is
    /// passed (which explicitly forces stderr even in TUI mode).

/// Frozen tracing configuration for the lifetime of one CLI invocation.
///
/// Construct via [`LogConfig::resolve`] from the parsed Cli.
///
/// # Examples
///
/// ```no_run
/// # use std::path::PathBuf;
/// # struct Cli { log_level: Option<String>, log_file: Option<PathBuf> }
/// # let cli = Cli { log_level: Some("debug".into()), log_file: None };
/// // (real call site is `LogConfig::resolve(&cli)` from main.rs)
/// ```
#[derive(Debug)]
#[non_exhaustive]
pub struct LogConfig {
    /// Raw env-filter string (e.g. "warn", "debug", "warn,agentprof_core=trace").
    /// Validated lazily by `init_tracing`; invalid values soft-fall to "warn".
    pub level_filter: String,

    pub writer: LogWriter,

    /// (i.e. `hash_path()` is bypassed). Set via env

    /// file writer (user explicitly passed `--log-file -`).
    pub force_stderr: bool,
}

impl Default for LogConfig {
    fn default() -> Self {
        Self {
            level_filter: "warn".to_string(),
            writer: LogWriter::Stderr,
            full_paths: false,
            force_stderr: false,
        }

impl LogConfig {
    /// Merge inputs into a `LogConfig` with `flag > env > default` precedence.
    ///
    /// Special cases:
    /// - `flag_log_file == Some("-")` → forces `LogWriter::Stderr` AND
    ///   sets `force_stderr = true` (so TUI guard knows not to redirect).
    /// - `env_full_paths != Some("1")` → `full_paths = false`.
    ///
    /// # Examples
    ///
    /// ```
    /// # use std::path::PathBuf;
    /// # // (function is pub(super) — not callable from outside the crate, so this
    /// # // doctest just compiles the type names against pub re-exports.)
    /// let cfg = agentprof_cli::observability::LogConfig::default();
    /// assert!(matches!(cfg.writer, agentprof_cli::observability::LogWriter::Stderr));
    /// ```
    pub fn from_inputs(
        flag_log_level: Option<String>,
        flag_log_file: Option<PathBuf>,
        env_log_level: Option<String>,
        env_log_file: Option<PathBuf>,
        env_full_paths: Option<String>,
    ) -> Self {
        // Level precedence: flag > env > default ("warn").
        // Also support the existing AGENTPROF_LOG var (read separately by the
        // caller — flag_log_level / env_log_level here are AGENTPROF_LOG_LEVEL).
        let level_filter = flag_log_level
            .or(env_log_level)
            .unwrap_or_else(|| "warn".to_string());

        // File precedence: flag > env > None.
        let file = flag_log_file.or(env_log_file);
        let (writer, force_stderr) = match file {
            Some(p) if p == PathBuf::from("-") => (LogWriter::Stderr, true),
            Some(p) => (LogWriter::File(p), false),
            None => (LogWriter::Stderr, false),
        };

        let full_paths = env_full_paths.as_deref() == Some("1");

        Self {
            level_filter,
            writer,
            full_paths,
            force_stderr,
        }
    }

    /// Resolve from CLI args + the standard env vars.
    ///
    /// Reads in this order (lower number wins):
    /// 1. `flag_log_level` (CLI `--log-level`)
    /// 2. `AGENTPROF_LOG_LEVEL` env
    /// 3. `AGENTPROF_LOG` env (backwards-compatible alias)
    /// 4. Default `"warn"`
    ///
    /// And for `--log-file`:
    /// 1. `flag_log_file` (CLI `--log-file`)
    /// 2. `AGENTPROF_LOG_FILE` env
    /// 3. None (= stderr by default; TUI may auto-redirect via
    ///    [`super::enter_tui_log_guard`])
    ///
    /// Plus: `AGENTPROF_LOG_FULL_PATHS=1` → opt out of path hashing.
    ///
    /// # Examples
    ///
    /// ```no_run
    /// # use std::path::PathBuf;
    /// // (Real call site is main.rs after Cli::parse().)
    /// let cfg = agentprof_cli::observability::LogConfig::resolve_from_env_and_flags(
    ///     Some("debug".into()),
    ///     None,
    /// );
    /// assert_eq!(cfg.level_filter, "debug");
    /// ```
    pub fn resolve_from_env_and_flags(
        flag_log_level: Option<String>,
        flag_log_file: Option<PathBuf>,
    ) -> Self {
        let env_log_level = std::env::var("AGENTPROF_LOG_LEVEL")
            .ok()
            .or_else(|| std::env::var("AGENTPROF_LOG").ok());
        let env_log_file = std::env::var("AGENTPROF_LOG_FILE").ok().map(PathBuf::from);
        let env_full_paths = std::env::var("AGENTPROF_LOG_FULL_PATHS").ok();
        Self::from_inputs(
            flag_log_level,
            flag_log_file,
            env_log_level,
            env_log_file,
            env_full_paths,
        )
    }
}

//! `init_tracing(&LogConfig) -> TracingHandle`: install a tracing
//! subscriber and return the appender's `WorkerGuard` for the
//! lifetime of the process.
//!
//! Soft-fall policy (ADR-0010 D-13): any subscriber installation
//! failure falls back to a default stderr writer + a one-shot
//! `tracing::warn!`, and continues. Tracing MUST NOT block CLI
//! startup.

use std::fs;
use std::io;

use tracing_appender::non_blocking::WorkerGuard;
use tracing_subscriber::{fmt, EnvFilter};

use super::config::{LogConfig, LogWriter};

/// Holds the appender `WorkerGuard` so the background writer thread
/// stays alive until process exit. Drop this LAST (it flushes the
/// buffered events).
///
/// # Examples
///
/// ```no_run
/// # use agentprof_cli::observability::{LogConfig, init_tracing};
/// let cfg = LogConfig::default();
/// let _handle = init_tracing(&cfg); // hold for process lifetime
/// tracing::info!("started");
/// ```
#[non_exhaustive]
pub struct TracingHandle {
    /// `Some` if the writer is a non-blocking file appender; `None` if
    /// the subscriber writes synchronously to stderr (no worker
    /// thread to keep alive).
    _appender_guard: Option<WorkerGuard>,
}

impl TracingHandle {
    fn stderr_only() -> Self {
        Self {
            _appender_guard: None,
        }
    }

    fn with_guard(g: WorkerGuard) -> Self {
        Self {
            _appender_guard: Some(g),
        }
    }
}

/// Install a tracing subscriber per `cfg`. Soft-fails to default
/// stderr on any error.
///
/// Returns a [`TracingHandle`] that MUST be held by `main` for the
/// process lifetime — dropping it stops the background appender
/// thread and loses any buffered events.
///
/// # Soft-fall scenarios
///
/// - Invalid level filter string ⇒ falls back to "warn".
/// - Log file parent dir missing AND cannot be created ⇒ falls back
///   to stderr writer.
/// - File open fails ⇒ falls back to stderr writer.
/// - Subscriber already installed (e.g. test environment) ⇒ swallowed.
///
/// Each soft-fall emits one `tracing::warn!`.
///
/// # Examples
///
/// ```no_run
/// # use agentprof_cli::observability::{LogConfig, init_tracing};
/// fn main() {
///     let cfg = LogConfig::resolve_from_env_and_flags(None, None);
///     let _handle = init_tracing(&cfg);
///     tracing::info!("started");
///     // ... rest of main ...
/// }
/// ```
pub fn init_tracing(cfg: &LogConfig) -> TracingHandle {
    let filter = build_env_filter(&cfg.level_filter);

    match &cfg.writer {
        LogWriter::Stderr => {
            let _ = fmt()
                .with_env_filter(filter)
                .with_writer(io::stderr)
                .try_init();
            TracingHandle::stderr_only()
        }
        LogWriter::File(path) => match try_install_file_writer(filter, path) {
            Ok(guard) => guard,
            Err(e) => {
                // Reinstall default stderr subscriber + warn.
                let _ = fmt()
                    .with_env_filter(build_env_filter(&cfg.level_filter))
                    .with_writer(io::stderr)
                    .try_init();
                tracing::warn!(
                    log_file = %path.display(),
                    error = %e,
                    "failed to initialize file log writer; falling back to stderr"
                );
                TracingHandle::stderr_only()
            }
        },
    }
}

fn build_env_filter(level_filter: &str) -> EnvFilter {
    EnvFilter::try_new(level_filter).unwrap_or_else(|e| {
        // Note: tracing isn't installed yet so this warn would be dropped;
        // we re-emit it after the subscriber comes up. For now we just
        // silently fall back to "warn" and let init_tracing re-emit a
        // visible warning if we want to.
        let _ = e;
        EnvFilter::new("warn")
    })
}

fn try_install_file_writer(
    filter: EnvFilter,
    path: &std::path::Path,
) -> Result<TracingHandle, FileWriterError> {
    let parent = path
        .parent()
        .ok_or(FileWriterError::NoParent)?;
    if !parent.exists() {
        fs::create_dir_all(parent).map_err(FileWriterError::Io)?;
    }
    let file_name = path
        .file_name()
        .ok_or(FileWriterError::NoFileName)?
        .to_string_lossy()
        .into_owned();
    let appender = tracing_appender::rolling::daily(parent, file_name);
    let (non_blocking, guard) = tracing_appender::non_blocking(appender);
    let _ = fmt()
        .with_env_filter(filter)
        .with_writer(non_blocking)
        .with_ansi(false)
        .try_init();
    Ok(TracingHandle::with_guard(guard))
}

#[derive(Debug)]
enum FileWriterError {
    NoParent,
    NoFileName,
    Io(io::Error),
}

impl std::fmt::Display for FileWriterError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            FileWriterError::NoParent => write!(f, "log file path has no parent directory"),
            FileWriterError::NoFileName => write!(f, "log file path has no file name component"),
            FileWriterError::Io(e) => write!(f, "io error creating log dir: {e}"),
        }
    }
}

//! TUI-aware tracing sink switch. Before entering ratatui's alt-screen,
//! call [`enter_tui_log_guard`] to (a) install a file-writer subscriber
//! under `$XDG_STATE_HOME/agentprof/agentprof.log` if no explicit file
//! is set, and (b) get an RAII guard whose Drop impl prints the log
//! path to stdout after the TUI cleanly exits.
//!
//! Soft-falls (ADR-0010 D-13):
//! - If `cfg.force_stderr` is true (user passed `--log-file -`), do
//!   NOT auto-switch — preserve the user's explicit choice.
//! - If `cfg.writer` is already a `File`, do NOT switch again.
//! - If XDG state dir resolution fails OR file open fails, emit a
//!   warning and return a no-op guard (subscriber stays as-is).

use std::path::PathBuf;

use super::config::{LogConfig, LogWriter};
use super::init::{init_tracing, TracingHandle};

/// Returned by [`enter_tui_log_guard`]; on Drop, prints
/// `"agentprof: trace log at <path>"` to stdout iff a file writer is
/// active. Idempotent (no-op on second drop).
#[non_exhaustive]
pub struct TuiLogGuard {
    log_path: Option<PathBuf>,
    _tracing_handle: Option<TracingHandle>,
}

impl Drop for TuiLogGuard {
    fn drop(&mut self) {
        if let Some(p) = self.log_path.take() {
            // After ratatui::terminal::leave() runs, stdout is the user's
            // shell again — println! is safe and visible.
            println!("agentprof: trace log at {}", p.display());
        }
    }
}

/// Auto-switch the active tracing writer to a rolling file under
/// `$XDG_STATE_HOME/agentprof/agentprof.log` before entering a TUI,
/// unless `cfg` already pins one.
///
/// Returns a no-op `TuiLogGuard` if the user explicitly forced stderr
/// (via `--log-file -`) or if anything in the switch path fails (a
/// warning is emitted in that case).
///
/// # Examples
///
/// ```no_run
/// # use agentprof_cli::observability::{LogConfig, enter_tui_log_guard};
/// # fn enter_tui() {}
/// # fn leave_tui() {}
/// fn run_tui_cmd(cfg: &LogConfig) {
///     let _log_guard = enter_tui_log_guard(cfg);
///     enter_tui();
///     // ... ratatui app loop ...
///     leave_tui();
///     // _log_guard drops here, after terminal::leave; prints path.
/// }
/// ```
pub fn enter_tui_log_guard(cfg: &LogConfig) -> TuiLogGuard {
    // User explicitly chose stderr — respect it (alt-screen corruption is
    // on them).
    if cfg.force_stderr {
        return TuiLogGuard {
            log_path: None,
            _tracing_handle: None,
        };
    }

    // User explicitly set a file — already file-writing; no switch needed,
    // but DO print the path on Drop so they see where logs went.
    if let LogWriter::File(p) = &cfg.writer {
        return TuiLogGuard {
            log_path: Some(p.clone()),
            _tracing_handle: None,
        };
    }

    // Default Stderr path → try to redirect to XDG state dir.
    match resolve_xdg_log_path() {
        Some(path) => {
            // Build a new LogConfig with the file writer; install it.
            let new_cfg = LogConfig {
                level_filter: cfg.level_filter.clone(),
                writer: LogWriter::File(path.clone()),
                full_paths: cfg.full_paths,
                force_stderr: false,
            };
            let handle = init_tracing(&new_cfg);
            TuiLogGuard {
                log_path: Some(path),
                _tracing_handle: Some(handle),
            }
        }
        None => {
            tracing::warn!(
                "could not resolve XDG_STATE_HOME or $HOME/.local/state; \
                 leaving tracing on stderr (may corrupt TUI alt-screen)"
            );
            TuiLogGuard {
                log_path: None,
                _tracing_handle: None,
            }
        }
    }
}

fn resolve_xdg_log_path() -> Option<PathBuf> {
    use directories::BaseDirs;
    let base = BaseDirs::new()?;
    let state_dir = base.state_dir().or_else(|| Some(base.cache_dir()))?;
    Some(state_dir.join("agentprof").join("agentprof.log"))
}

    about = "Perf flamegraph + ROI profiler for AI coding agents"
)]
struct Cli {
    /// Tracing level filter (trace|debug|info|warn|error) or full
    /// env-filter syntax. Default: env `AGENTPROF_LOG_LEVEL` /
    /// `AGENTPROF_LOG`, then `"warn"`.
    #[arg(long, global = true)]
    log_level: Option<String>,

    /// Write trace events to this file instead of stderr. Use `-` to
    /// force stderr (overrides TUI auto-redirect). Default: stderr for
    /// non-TUI, auto under `$XDG_STATE_HOME/agentprof/agentprof.log`
    /// for `--export tui` and `watch`.
    #[arg(long, global = true)]
    log_file: Option<PathBuf>,

    #[command(subcommand)]
    cmd: SubCmd,
}

#[derive(Subcommand, Debug)]
enum SubCmd {
    /// Analyze a single agent session and produce a markdown or JSON report.
    Analyze(cmd::analyze::AnalyzeCmd),
    /// List recent agent sessions in a compact table.
    List(cmd::list::ListCmd),
    /// Aggregate metrics across many recent sessions.
    Aggregate(cmd::aggregate::AggregateCmd),
    /// Live-refresh TUI: monitor session file(s) and redraw on change (M1.6.3).
    Watch(cmd::watch::WatchCmd),
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let cfg = observability::LogConfig::resolve_from_env_and_flags(
        cli.log_level.clone(),
        cli.log_file.clone(),
    );
    let _tracing_handle = observability::init_tracing(&cfg);

    match run(cli, &cfg) {
        Ok(()) => ExitCode::SUCCESS,
        Err(err) => {
            // NOTE: keep eprintln here (D-7 exception): the user-facing
            // final error message MUST reach stderr even if the tracing
            // subscriber is pointed at a file.
            eprintln!("agentprof: {err:#}");
            ExitCode::from(classify_error(&err))
        }
    }
}

fn run(cli: Cli, cfg: &observability::LogConfig) -> Result<()> {
    match cli.cmd {
        SubCmd::Analyze(c) => cmd::analyze::run(c, cfg),
        SubCmd::List(c) => cmd::list::run(c, cfg),
        SubCmd::Aggregate(c) => cmd::aggregate::run(c, cfg),
        SubCmd::Watch(c) => cmd::watch::run(c, cfg),
    }
}

fn classify_error(err: &anyhow::Error) -> u8 {
    err.downcast_ref::<cmd::analyze::ExitKind>()
        .map_or(1, |k| *k as u8)
}
