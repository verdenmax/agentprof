# F1.7 — Models View + session-level token metrics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a new `Models` TUI view (key `4`) showing per-model session-level token totals (input / output / cache_read / cache_write) parsed from Copilot CLI's `session.shutdown.modelMetrics`. Centered-placeholder empty-state when no `session.shutdown` event has been emitted yet (live `watch` mode / crashed session). Data flows through `Event::payload_model_metrics()` trait extension method → `Episodes.model_metrics` (collected during `derive_episodes` walk) → `AnalysisReport.model_metrics` (cloned by `analyze()` like `episodes.warnings`).

**Architecture:** Four-layer change matching the ADR-0005 / ADR-0011 extension-method pattern. Layer 1 `agentprof-core::analyzer` adds `pub struct ModelUsage { input_tokens, output_tokens, cache_read_tokens, cache_write_tokens: u64 }` with `new()` + `total()` const helpers. Layer 2 `agentprof-core::adapter` adds `fn payload_model_metrics(&self) -> Option<BTreeMap<String, ModelUsage>>` to the `Event` trait with `None` default. Layer 3 `agentprof-adapters::copilot::event` overrides on `CopilotEvent::Shutdown` variant by walking the existing free-form `ShutdownData.model_metrics: BTreeMap<String, serde_json::Value>` tree (`.get("usage")?.get("inputTokens").and_then(.as_u64).unwrap_or(0)` pattern, robust against wire schema drift). Layer 4 `agentprof-core::episode::derive::derive_episodes` populates `Episodes.model_metrics` (last-wins) from the trait method; `agentprof-core::analyzer::analyze` clones into `AnalysisReport.model_metrics`. Layer 5 `agentprof-tui` adds `View::Models` enum variant + `pub mod views::models` (render fn + state) + `AppState.models_selected` field + key `4` dispatch + WatchRunner round-trip + help overlay legend.

**Tech Stack:** Rust 2021 (MSRV 1.78); existing `serde_json` + `ratatui` + `crossterm` + `insta` + `tracing` workspace deps. **No new dependencies.**

**Spec:** [`docs/superpowers/specs/2026-06-03-f1.7-models-view-design.md`](../specs/2026-06-03-f1.7-models-view-design.md) (commit `4a8e5ed`)

**ADR:** [`docs/internals/adr-0012-session-model-metrics-and-models-view.md`](../../internals/adr-0012-session-model-metrics-and-models-view.md) (commit `2aaf778`)

/// Per-model token-usage rollup, sourced from session-level events
/// (e.g. Copilot CLI's `session.shutdown.modelMetrics`).
///
/// All four fields default to `0` when the wire format omits them.
/// Cardinality discrimination ("known-zero vs unreported") is intentionally
/// elided in v1 — Copilot CLI consistently reports all four fields when
/// `usage` is present. See ADR-0012 D-15 for rationale.
///
/// # Examples
///
/// ```
/// use agentprof_core::analyzer::ModelUsage;
/// let mut u = ModelUsage::new();
/// u.input_tokens = 100;
/// u.output_tokens = 50;
/// assert_eq!(u.total(), 150);
/// ```
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[non_exhaustive]
pub struct ModelUsage {
    /// Input (request prompt) tokens.
    pub input_tokens: u64,
    /// Output (response generation) tokens.
    pub output_tokens: u64,
    /// Cache-read tokens (re-used context from prompt cache).
    pub cache_read_tokens: u64,
    /// Cache-write tokens (new context entered into the prompt cache).
    pub cache_write_tokens: u64,
}

impl ModelUsage {
    /// Construct a zero-initialized rollup.
    ///
    /// # Examples
    ///
    /// ```
    /// use agentprof_core::analyzer::ModelUsage;
    /// let u = ModelUsage::new();
    /// assert_eq!(u.input_tokens, 0);
    /// ```
    #[must_use]
    pub const fn new() -> Self {
        Self {
            input_tokens: 0,
            output_tokens: 0,
            cache_read_tokens: 0,
            cache_write_tokens: 0,
        }
    }

    /// Total of all four token categories. Saturating add (returns
    /// `u64::MAX` on overflow rather than panicking).
    ///
    /// # Examples
    ///
    /// ```
    /// use agentprof_core::analyzer::ModelUsage;
    /// let u = ModelUsage {
    ///     input_tokens: 10,
    ///     output_tokens: 20,
    ///     cache_read_tokens: 30,
    ///     cache_write_tokens: 40,
    /// };
    /// assert_eq!(u.total(), 100);
    /// ```
    #[must_use]
    pub const fn total(&self) -> u64 {
        self.input_tokens
            .saturating_add(self.output_tokens)
            .saturating_add(self.cache_read_tokens)
            .saturating_add(self.cache_write_tokens)
    }
}
```

```rust
    /// Returns per-model token-usage rollup for [`Self::Shutdown`]
    /// (the only Copilot wire event carrying it). Walks the existing
    /// free-form `model_metrics: BTreeMap<String, serde_json::Value>`
    /// tree, reading `.get("usage")?.get("<key>").and_then(as_u64).unwrap_or(0)`
    /// for each token field.
    ///
    /// Models whose `usage` subtree is absent are skipped (not
    /// converted to zero-init `ModelUsage`). Returns `None` if no
    /// model has a `usage` subtree.
    ///
    /// Free-form Value walking (rather than typed intermediate struct
    /// deserialization) is robust against Copilot wire schema drift —
    /// new fields under `usage` don't break parsing; field renames
    /// just produce `0` instead of failing. See ADR-0012 D-7.
    ///
    /// # Examples
    ///
    /// ```
    /// use agentprof_adapters::copilot::CopilotEvent;
    /// assert!(CopilotEvent::Unknown.payload_model_metrics().is_none());
    /// ```
    #[must_use]
    pub fn payload_model_metrics(
        &self,
    ) -> Option<std::collections::BTreeMap<String, agentprof_core::analyzer::ModelUsage>>
    {
        let Self::Shutdown(env) = self else { return None };
        let mut out = std::collections::BTreeMap::new();
        for (model, metrics_value) in &env.data.model_metrics {
            let Some(usage) = metrics_value.get("usage") else { continue };
            let read_u64 = |key: &str| -> u64 {
                usage.get(key).and_then(serde_json::Value::as_u64).unwrap_or(0)
            };
            out.insert(
                model.clone(),
                agentprof_core::analyzer::ModelUsage {
                    input_tokens: read_u64("inputTokens"),
                    output_tokens: read_u64("outputTokens"),
                    cache_read_tokens: read_u64("cacheReadTokens"),
                    cache_write_tokens: read_u64("cacheWriteTokens"),
                },
            );
        }
        if out.is_empty() {
            None
        } else {
            Some(out)
        }
    }
```

//! Session-level per-model token-usage view (key `4`, F1.7).
//!
//! Sources from [`agentprof_core::analyzer::AnalysisReport::model_metrics`].
//! When the session has emitted a `session.shutdown` event, shows a

use ratatui::layout::{Constraint, Direction, Layout, Rect};

/// Render the Models view body.
///
/// Two branches:
/// - `app_state.report.model_metrics` is `Some(non_empty)` → table sorted
///   by input desc + totals footer row.
/// - Otherwise → centered placeholder + multi-line "no shutdown event
///   yet" explanation.
///
/// # Examples
///
/// ```no_run
/// use agentprof_core::adapter::AgentKind;
/// use agentprof_core::analyzer::AnalysisReport;
/// use agentprof_core::episode::Episodes;
/// use agentprof_core::model::SessionMeta;
/// use agentprof_tui::app::state::AppState;
/// use agentprof_tui::views::models::render;
/// use chrono::Utc;
/// use ratatui::backend::TestBackend;
/// use ratatui::Terminal;
///
/// let meta = SessionMeta::new("s".into(), AgentKind::Copilot, Utc::now(), false);
/// let report = AnalysisReport::new(meta);
/// let episodes = Episodes::new();
/// let state = AppState::new(&report, &episodes);
///
/// let backend = TestBackend::new(100, 20);
/// let mut terminal = Terminal::new(backend).expect("backend");
/// terminal
///     .draw(|f| render(f, f.area(), &state))
///     .expect("draw");
/// ```
pub fn render(f: &mut Frame<'_>, area: Rect, app_state: &crate::app::state::AppState<'_>) {
    let block = Block::default()
        .borders(Borders::ALL)
        .title(" Models — session token usage ");
    let inner = block.inner(area);
    f.render_widget(block, area);

    // Split inner: body + 1-line footer (footer doesn't scroll).
    let chunks = Layout::default()
        .direction(Direction::Vertical)
        .constraints([Constraint::Min(1), Constraint::Length(1)])
        .split(inner);
    let body_area = chunks[0];
    let footer_area = chunks[1];

    match app_state.report.model_metrics.as_ref() {
        Some(metrics) if !metrics.is_empty() => {
            render_with_data(f, body_area, footer_area, metrics, app_state.models_selected);
        }
        _ => {
            render_empty_state(f, body_area, footer_area);
        }
    }
}

/// Render the with-data branch — table + totals footer.
fn render_with_data(
    f: &mut Frame<'_>,
    body_area: Rect,
    footer_area: Rect,
    metrics: &std::collections::BTreeMap<String, ModelUsage>,
    selected: usize,
) {
    // Sort by input_tokens desc (D-11).
    let mut rows: Vec<(&String, &ModelUsage)> = metrics.iter().collect();
    rows.sort_by(|a, b| b.1.input_tokens.cmp(&a.1.input_tokens));

    // Compute totals.
    let totals = rows.iter().fold(ModelUsage::new(), |mut acc, (_, u)| {
        acc.input_tokens = acc.input_tokens.saturating_add(u.input_tokens);
        acc.output_tokens = acc.output_tokens.saturating_add(u.output_tokens);
        acc.cache_read_tokens = acc.cache_read_tokens.saturating_add(u.cache_read_tokens);
        acc.cache_write_tokens = acc.cache_write_tokens.saturating_add(u.cache_write_tokens);
        acc
    });

    // Header row + data rows + separator + totals.
    let header = Row::new(vec!["Model", " Input", "Output", "Cache R", "Cache W"])
        .style(Style::default().add_modifier(Modifier::BOLD));

    let data_rows: Vec<Row<'_>> = rows
        .iter()
        .enumerate()
        .map(|(idx, (model, u))| {
            let is_selected = idx == selected;
            let style = if is_selected {
                Style::default().add_modifier(Modifier::REVERSED)
            } else {
                Style::default()
            };
            Row::new(vec![
                format_token_u64_short(u32_or_max(u.input_tokens)),
                format_token_u64_short(u32_or_max(u.output_tokens)),
                format_token_u64_short(u32_or_max(u.cache_read_tokens)),
                format_token_u64_short(u32_or_max(u.cache_write_tokens)),
            ])
            .style(style)
        })
        .collect();

    // Actually wait — the format_tokens_short helper from F1.6 takes
    // Option<u32>. We need a u64-aware variant. Build inline:
    // see helper `format_token_u64_short` below.

    let totals_style = Style::default()
        .fg(Color::Cyan)
        .add_modifier(Modifier::BOLD);
    let totals_row = Row::new(vec![
        "Total".to_string(),
        format_token_u64_short(totals.input_tokens),
        format_token_u64_short(totals.output_tokens),
        format_token_u64_short(totals.cache_read_tokens),
        format_token_u64_short(totals.cache_write_tokens),
    ])
    .style(totals_style);

    // Build full row list with model name as first cell.
    let full_rows: Vec<Row<'_>> = std::iter::once(header)
        .chain(rows.iter().enumerate().map(|(idx, (model, u))| {
            let is_selected = idx == selected;
            let style = if is_selected {
                Style::default().add_modifier(Modifier::REVERSED)
            } else {
                Style::default()
            };
            Row::new(vec![
                (*model).clone(),
                format_token_u64_short(u.input_tokens),
                format_token_u64_short(u.output_tokens),
                format_token_u64_short(u.cache_read_tokens),
                format_token_u64_short(u.cache_write_tokens),
            ])
            .style(style)
        }))
        .chain(std::iter::once(totals_row))
        .collect();

    let widths = [
        Constraint::Min(40),
        Constraint::Length(10),
        Constraint::Length(10),
        Constraint::Length(10),
        Constraint::Length(10),
    ];
    let table = Table::new(full_rows, widths).column_spacing(1);
    f.render_widget(table, body_area);

    // Footer hint.
    let model_count = metrics.len();
    let footer_text = format!(
        "session has {model_count} model{plural} · sorted by input desc · \
         j/k navigate · Esc / 1 switches to view 1",
        plural = if model_count == 1 { "" } else { "s" }
    );
    let footer = Paragraph::new(footer_text)
        .style(Style::default().add_modifier(Modifier::DIM));
    f.render_widget(footer, footer_area);
}

/// Format a `u64` token count as a 5-char wide right-padded string,
/// suitable for table cells.
///
/// Uses k/M/G abbreviations for large counts. Sibling helper to
/// `views::format::format_tokens_short` (which takes `Option<u32>`);
/// this one handles `u64` for session-level totals which can exceed
/// `u32::MAX`.
///
/// # Examples
///
/// ```
/// use agentprof_tui::views::models::format_token_u64_short;
/// assert_eq!(format_token_u64_short(42), "   42");
/// assert_eq!(format_token_u64_short(1234), " 1.2k");
/// assert_eq!(format_token_u64_short(123_456), " 123k");
/// assert_eq!(format_token_u64_short(1_500_000), " 1.5M");
/// assert_eq!(format_token_u64_short(15_000_000), "  15M");
/// assert_eq!(format_token_u64_short(2_500_000_000), " 2.5G");
/// ```
#[must_use]
pub fn format_token_u64_short(n: u64) -> String {
    if n < 1_000 {
        format!("{n:>5}")
    } else if n < 100_000 {
        // Truncate to one decimal: e.g. 99_999 → "99.9k".
        let tenths = n / 100;
        let display = tenths as f64 / 10.0;
        format!("{display:>5.1}k")
            .chars()
            .take(5)
            .collect::<String>()
    } else if n < 1_000_000 {
        format!("{:>4}k", n / 1_000)
    } else if n < 10_000_000 {
        let tenths_m = n / 100_000;
        let display = tenths_m as f64 / 10.0;
        format!("{display:>4.1}M")
    } else if n < 1_000_000_000 {
        format!("{:>4}M", n / 1_000_000)
    } else if n < 10_000_000_000 {
        let tenths_g = n / 100_000_000;
        let display = tenths_g as f64 / 10.0;
        format!("{display:>4.1}G")
    } else {
        format!("{:>4}G", n / 1_000_000_000)
    }
}

// Tiny helper: saturating u64 → u32 (no-op for small values, caps at
// u32::MAX for huge ones — but format_token_u64_short takes u64 directly
// so this helper is unused in the actual call sites above; left as a
// reminder if F2.x ever wants a u32 conversion).
#[allow(dead_code)]
fn u32_or_max(n: u64) -> u32 {
    n.try_into().unwrap_or(u32::MAX)
}
