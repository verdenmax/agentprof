# M1.7 v0.1.0 release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `agentprof` v0.1.0 as the project's first public release — installable via a one-line shell installer from a GitHub Release built by `cargo-dist` across 4 platforms.

**Architecture:** 8 implementation tasks (T1–T8) following spec §9 commits #4–#11. T1–T7 are pure local work that lands on the existing local `main` branch with no GitHub repo required; T8 is the trigger commit + tag push that activates `release.yml`. Each task ends with its own commit so failures are revertible.

**Tech Stack:** `cargo-dist` 0.21.x (dev tool, manages the release pipeline) / GitHub Actions (build infra) / `curl + jq` OR `gh` (for SHA-pin lookups) / Keep-a-Changelog format / no new runtime dependencies.

**Spec:** [`docs/superpowers/specs/2026-06-06-m1.7-release-design.md`](../specs/2026-06-06-m1.7-release-design.md)
**ADR:** [`docs/internals/adr-0014-v0.1.0-release-strategy.md`](../../internals/adr-0014-v0.1.0-release-strategy.md)
