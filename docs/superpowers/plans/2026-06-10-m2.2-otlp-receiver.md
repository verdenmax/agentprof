# M2.2 OTLP Receiver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `agentprof ingest-otlp` standalone subcommand that runs a stateful OTLP receiver (gRPC 4317 + HTTP/protobuf 4318) accepting Logs + Metrics + Traces, deriving per-session `AnalysisReport` + `Episodes` from OTel signals, persisting via the existing M2.1/M2.1.1 storage layer.

**Architecture:** New `storage::otlp` submodule (gated by existing `otlp` feature flag, NOT a new crate). Tonic 3 gRPC services + axum 3 HTTP endpoints both feed a common `pipeline` → `mapper` (OTLP → `TypedEvent`) → `session_router` (per-session in-memory buffer keyed by resource `session.id` attribute) → flush via `storage::upsert_report` + `storage::upsert_episodes`. Auth: bearer token + optional rustls TLS / mTLS. OTLP receiver does NOT implement `SessionDataSource` (push vs pull; see ADR-0021 §"Decision").

**Tech Stack:** Rust 2021 + MSRV 1.78 / tonic 0.12 (existing, gated) + opentelemetry-otlp 0.27 (existing, gated) + opentelemetry / opentelemetry_sdk 0.27 (existing, gated) + tokio (existing) + **NEW**: axum 0.7 (HTTP server), rustls 0.23 (TLS / mTLS), bytes 1.x (proto decode), tower 0.5 (axum middleware, transitive). Tests: assert_cmd + integration via real `opentelemetry-otlp` client SDK; rcgen for test TLS certs.

**Spec:** [`docs/superpowers/specs/2026-06-10-m2.2-otlp-receiver-design.md`](../specs/2026-06-10-m2.2-otlp-receiver-design.md)

**ADR drafted in T10:** ADR-0021 (OTLP receiver architecture) + ADR-0018 footnote (OTLP NOT a SessionDataSource impl)

### Task 1.2: build.rs for tonic proto codegen

**Files:**
- Create: `crates/agentprof-storage/build.rs`

**Background**: The `opentelemetry-otlp` crate ships the proto types we need for client-side ingestion, but server-side tonic services require generated `tonic::server::Server<S>` traits. `tonic_build::configure().compile(...)` generates these from `.proto` files.

The `opentelemetry-proto` upstream crate also exposes a bundled-protos feature that includes the generated types. We could use that — but it generates the **client** stubs only, not server stubs. So we run our own `tonic_build` against the proto files that ship inside `opentelemetry-proto`.

- [ ] **Step 1: Write the build.rs**

Create `crates/agentprof-storage/build.rs`:

```rust
//! Build script for `agentprof-storage`.
//!
//! When the `otlp` feature is enabled, generates tonic server bindings
//! for the three OTLP collector services (Logs / Metrics / Trace) by
//! invoking `tonic_build` against the proto files vendored by the
//! `opentelemetry-proto` crate.
//!
//! When the `otlp` feature is disabled, this script is a no-op so the
//! base build path stays fast.

fn main() {
    println!("cargo:rerun-if-changed=build.rs");

    #[cfg(feature = "otlp")]
    {
        // The opentelemetry-proto crate vendors the upstream protos under
        // its source tree. tonic_build needs proto file paths + include dirs.
        // We discover them via cargo metadata at build time so we don't
        // hardcode a path that's brittle across opentelemetry-proto versions.
        //
        // For v0.27 the layout is: <crate>/src/proto/opentelemetry/proto/...
        //
        // The 3 service descriptors we need:
        let protos = [
            "opentelemetry/proto/collector/logs/v1/logs_service.proto",
            "opentelemetry/proto/collector/metrics/v1/metrics_service.proto",
            "opentelemetry/proto/collector/trace/v1/trace_service.proto",
        ];

        // Locate the opentelemetry-proto crate's vendored proto dir.
        let proto_root = locate_otel_proto_root()
            .expect("could not find opentelemetry-proto proto dir; \
                     check Cargo.lock has opentelemetry-proto");

        let include_dirs = [proto_root.clone()];
        let proto_paths: Vec<std::path::PathBuf> = protos
            .iter()
            .map(|p| proto_root.join(p))
            .collect();

        for p in &proto_paths {
            assert!(p.exists(), "missing OTLP proto file: {}", p.display());
            println!("cargo:rerun-if-changed={}", p.display());
        }

        tonic_build::configure()
            .build_client(false)  // we are the server; opentelemetry-otlp ships clients
            .build_server(true)
            .out_dir(std::env::var("OUT_DIR").expect("OUT_DIR set by cargo"))
            .compile_protos(&proto_paths, &include_dirs)
            .expect("tonic_build proto codegen failed");
    }
}

#[cfg(feature = "otlp")]
fn locate_otel_proto_root() -> Option<std::path::PathBuf> {
    // Discover the opentelemetry-proto crate's source dir via the
    // OUT_DIR hierarchy and Cargo metadata.
    //
    // Strategy: walk up from OUT_DIR until we find target/, then look
    // at registry cache for opentelemetry-proto-<ver>/src/proto.
    //
    // Simpler / more robust: read the env var that cargo sets for direct
    // path dependencies. opentelemetry-proto isn't a direct dep — it
    // comes via opentelemetry-otlp — so we use cargo_metadata at build
    // time. Adding cargo_metadata as a build-dep is overkill; instead
    // walk the Cargo registry cache directly.
    use std::path::PathBuf;
    let manifest_dir = std::env::var_os("CARGO_MANIFEST_DIR")?;
    let workspace_root = PathBuf::from(manifest_dir).parent()?.parent()?.to_path_buf();

    // Look for the vendored proto under the cargo registry cache.
    // CARGO_HOME defaults to ~/.cargo, but is overridable.
    let cargo_home = std::env::var_os("CARGO_HOME")
        .map(PathBuf::from)
        .or_else(|| std::env::var_os("HOME").map(|h| PathBuf::from(h).join(".cargo")))?;

    let registry_src = cargo_home.join("registry").join("src");
    if !registry_src.exists() {
        return None;
    }

    // Walk the registry src dirs (one per registry index) for a dir
    // matching opentelemetry-proto-*.
    for entry in std::fs::read_dir(&registry_src).ok()? {
        let entry = entry.ok()?;
        let path = entry.path();
        if !path.is_dir() {
            continue;
        }
        for sub in std::fs::read_dir(&path).ok()? {
            let sub = sub.ok()?;
            let name = sub.file_name();
            let name_str = name.to_string_lossy();
            if name_str.starts_with("opentelemetry-proto-") {
                let proto_dir = sub.path().join("src").join("proto");
                if proto_dir.exists() {
                    return Some(proto_dir);
                }
            }
        }
    }
    // Last-ditch fallback: workspace-local vendored copy (not present
    // by default; engineer can add one if cargo registry isn't usable).
    let local = workspace_root.join("vendor").join("opentelemetry-proto").join("proto");
    if local.exists() {
        return Some(local);
    }
    None
}
```

**IMPORTANT**: this build.rs is **fragile** with respect to the
opentelemetry-proto crate's internal layout. If the vendored proto path
changes in a future version, this code will fail at build time with a
clear "missing OTLP proto file" panic message. If you hit this:

1. Verify `cargo doc -p opentelemetry-proto --open` to inspect what
   protos the current version ships.
2. Adjust the `protos` array's paths to match.
3. If `opentelemetry-proto` removes vendored protos entirely (unlikely
   pre-1.0), vendor them ourselves under `crates/agentprof-storage/proto/`.

//! Error types for the OTLP receiver subsystem (M2.2).

use std::net::SocketAddr;
use std::path::PathBuf;

/// Top-level error for OTLP server lifecycle (bind / TLS init / transport).
#[derive(thiserror::Error, Debug)]
#[non_exhaustive]
pub enum OtlpServerError {
    /// Failed to bind on the configured listener address.
    #[error("bind error on {addr}: {source}")]
    Bind {
        /// Address we tried to bind on.
        addr: SocketAddr,
        /// Underlying IO error.
        #[source]
        source: std::io::Error,
    },
    /// TLS configuration (cert / key load + parse) failed.
    #[error("tls config error: {message}")]
    TlsConfig {
        /// Human-readable diagnostic.
        message: String,
    },
    /// Tonic transport-level error (server lifecycle).
    #[error("tonic transport error: {0}")]
    Tonic(#[from] tonic::transport::Error),
    /// Hyper / axum HTTP server error.
    #[error("http server error: {0}")]
    Http(String),
    /// I/O error reading a config-supplied PEM file.
    #[error("io error at {path}: {source}")]
    Io {
        /// File path.
        path: PathBuf,
        /// Underlying io::Error.
        #[source]
        source: std::io::Error,
    },
    /// Config validation rejected the resolved settings.
    #[error("config validation: {0}")]
    Config(String),
}

/// Errors raised by the OTLP → TypedEvent mapper (per-event, recoverable).
#[derive(thiserror::Error, Debug, Clone)]
#[non_exhaustive]
pub enum MapperError {
    /// Required resource attribute missing from the OTLP envelope.
    #[error("missing required resource attribute: {name}")]
    MissingResourceAttr {
        /// Attribute name we looked for (e.g. "session.id").
        name: &'static str,
    },
    /// Timestamp field couldn't be parsed.
    #[error("invalid timestamp: {0}")]
    BadTimestamp(String),
    /// Recognized signal kind but unknown event name (e.g. unrecognized `claude_code.*`).
    #[error("unknown event name: {0}")]
    UnknownEventName(String),
    /// Recognized event name but payload shape mismatched.
    #[error("payload shape mismatch for {event_name}: {message}")]
    PayloadMismatch {
        /// The event name we were parsing.
        event_name: String,
        /// What went wrong.
        message: String,
    },
}

/// Errors raised by the per-session router during ingest / flush.
#[derive(thiserror::Error, Debug)]
#[non_exhaustive]
pub enum RouterError {
    /// Persistence layer error during a buffer flush.
    #[error("storage error: {0}")]
    Storage(#[from] crate::SqliteError),
    /// Mapper error encountered while routing an event.
    #[error("mapper error: {0}")]
    Mapper(#[from] MapperError),
    /// Buffer hit OOM cap before flush completed.
    #[error("session {session_id} buffer hit OOM cap (bytes={bytes}, events={events})")]
    BufferOom {
        /// The offending session.
        session_id: String,
        /// Estimated bytes at OOM trip.
        bytes: usize,
        /// Event count at OOM trip.
        events: usize,
    },
}
```

///
/// Built from a [`PartialOtlpServerConfig`] (TOML-deserialized) via
/// [`OtlpServerConfig::from_partial`]. CLI flag layer can post-process
/// the resolved config by overwriting specific fields.
///
/// # Examples
/// ```
/// use agentprof_storage::otlp::config::OtlpServerConfig;
/// let cfg = OtlpServerConfig::default();
/// assert_eq!(cfg.listen_grpc.unwrap().to_string(), "127.0.0.1:4317");
/// ```
#[derive(Debug, Clone)]
#[non_exhaustive]
pub struct OtlpServerConfig {
    /// gRPC listener address. `None` disables the gRPC listener.
    pub listen_grpc: Option<SocketAddr>,
    /// HTTP/protobuf listener address. `None` disables the HTTP listener.
    pub listen_http: Option<SocketAddr>,
    /// Bearer token required on every request (Authorization: Bearer <T>).
    /// `None` disables bearer auth.
    pub listen_token: Option<String>,
    /// TLS server certificate path (PEM). When `Some`, **both** listeners
    /// serve over TLS.
    pub tls_cert: Option<PathBuf>,
    /// TLS server key path (PEM). Required when `tls_cert` is `Some`.
    pub tls_key: Option<PathBuf>,
    /// Client CA path (PEM). When `Some`, requires + verifies client certs
    /// (mutual TLS). Implies TLS (so `tls_cert` + `tls_key` must also be set).
    pub tls_client_ca: Option<PathBuf>,
    /// Per-session idle flush threshold. Default 5 min.
    pub session_idle_timeout: Duration,
    /// Maximum graceful shutdown wait after SIGINT / SIGTERM. Default 10s.
    pub shutdown_grace: Duration,
}

impl Default for OtlpServerConfig {
    fn default() -> Self {
        Self {
            listen_grpc: Some("127.0.0.1:4317".parse().expect("hardcoded valid SocketAddr")),
            listen_http: Some("127.0.0.1:4318".parse().expect("hardcoded valid SocketAddr")),
            listen_token: None,
            tls_cert: None,
            tls_key: None,
            tls_client_ca: None,
            session_idle_timeout: Duration::from_secs(300),
            shutdown_grace: Duration::from_secs(10),
        }
    }
}

impl OtlpServerConfig {
    /// Build a resolved config from a TOML-deserialized partial.
    ///
    /// # Errors
    /// - [`OtlpServerError::Config`] if a SocketAddr string is malformed.
    /// - [`OtlpServerError::Config`] if a duration string is unparseable.
    pub fn from_partial(p: PartialOtlpServerConfig) -> Result<Self, OtlpServerError> {
        let mut cfg = Self::default();

        if let Some(s) = p.listen_grpc {
            cfg.listen_grpc = parse_optional_addr(&s, "listen_grpc")?;
        }
        if let Some(s) = p.listen_http {
            cfg.listen_http = parse_optional_addr(&s, "listen_http")?;
        }
        cfg.listen_token = p.listen_token.filter(|t| !t.is_empty());
        cfg.tls_cert = p.tls_cert;
        cfg.tls_key = p.tls_key;
        cfg.tls_client_ca = p.tls_client_ca;
        if let Some(s) = p.session_idle_timeout {
            cfg.session_idle_timeout = parse_duration(&s, "session_idle_timeout")?;
        }
        if let Some(s) = p.shutdown_grace {
            cfg.shutdown_grace = parse_duration(&s, "shutdown_grace")?;
        }

        Ok(cfg)
    }

    /// Validate cross-field invariants (TLS pairs, mTLS implies TLS, etc.).
    ///
    /// # Errors
    /// [`OtlpServerError::Config`] when any invariant is violated.
    pub fn validate(&self) -> Result<(), OtlpServerError> {
        if self.listen_grpc.is_none() && self.listen_http.is_none() {
            return Err(OtlpServerError::Config(
                "both --listen-grpc and --listen-http disabled; nothing to serve".into(),
            ));
        }
        match (self.tls_cert.is_some(), self.tls_key.is_some()) {
            (true, false) | (false, true) => {
                return Err(OtlpServerError::Config(
                    "--tls-cert and --tls-key must both be set or both unset".into(),
                ));
            }
            _ => {}
        }
        if self.tls_client_ca.is_some() && self.tls_cert.is_none() {
            return Err(OtlpServerError::Config(
                "--tls-client-ca requires --tls-cert + --tls-key (mTLS implies server TLS)".into(),
            ));
        }
        Ok(())
    }
}

/// User-supplied partial config (TOML-friendly, all fields optional).
#[derive(Debug, Default, Clone, serde::Deserialize)]
#[serde(default, deny_unknown_fields)]
pub struct PartialOtlpServerConfig {
    /// gRPC listener address as a string ("host:port"); empty string disables.
    pub listen_grpc: Option<String>,
    /// HTTP listener address.
    pub listen_http: Option<String>,
    /// Bearer token.
    pub listen_token: Option<String>,
    /// TLS cert path.
    pub tls_cert: Option<PathBuf>,
    /// TLS key path.
    pub tls_key: Option<PathBuf>,
    /// mTLS client CA path.
    pub tls_client_ca: Option<PathBuf>,
    /// Idle timeout as humantime string (e.g. "5m").
    pub session_idle_timeout: Option<String>,
    /// Shutdown grace as humantime string.
    pub shutdown_grace: Option<String>,
}

fn parse_optional_addr(s: &str, field: &'static str) -> Result<Option<SocketAddr>, OtlpServerError> {
    let t = s.trim();
    if t.is_empty() {
        return Ok(None);
    }
    SocketAddr::from_str(t).map(Some).map_err(|e| {
        OtlpServerError::Config(format!("invalid {field}: {t:?}: {e}"))
    })
}

fn parse_duration(s: &str, field: &'static str) -> Result<Duration, OtlpServerError> {
    // Minimal humantime-style parser to avoid pulling humantime crate.
    // Supports: <N>s, <N>m, <N>h. Numeric N must be non-negative integer.
    let t = s.trim();
    if t.is_empty() {
        return Err(OtlpServerError::Config(format!("empty {field} duration")));
    }
    let (num_str, unit) = t.split_at(
        t.find(|c: char| !c.is_ascii_digit())
            .ok_or_else(|| OtlpServerError::Config(format!("{field}: missing unit on {t:?}; use Ns/Nm/Nh")))?,
    );
    let n: u64 = num_str.parse().map_err(|e| {
        OtlpServerError::Config(format!("{field}: invalid number in {t:?}: {e}"))
    })?;
    let secs = match unit {
        "s" => n,
        "m" => n.saturating_mul(60),
        "h" => n.saturating_mul(3600),
        other => {
            return Err(OtlpServerError::Config(format!(
                "{field}: unknown unit {other:?} in {t:?}; use s/m/h"
            )));
        }
    };
    Ok(Duration::from_secs(secs))
}

//! Tonic gRPC server hosting the 3 OTLP collector services.
//!
//! Bind / serve / shutdown lifecycle. Per-request handling delegates
//! to [`IngestPipeline`] via Arc-shared state.

use std::sync::Arc;

use opentelemetry_proto::tonic::collector::{
    logs::v1::{
        logs_service_server::{LogsService, LogsServiceServer},
        ExportLogsServiceRequest, ExportLogsServiceResponse,
    },
    metrics::v1::{
        metrics_service_server::{MetricsService, MetricsServiceServer},
        ExportMetricsServiceRequest, ExportMetricsServiceResponse,
    },
    trace::v1::{
        trace_service_server::{TraceService, TraceServiceServer},
        ExportTraceServiceRequest, ExportTraceServiceResponse,
    },
};
use tokio::sync::oneshot;
use tonic::{transport::Server, Request, Response, Status};

use crate::otlp::config::OtlpServerConfig;
use crate::otlp::error::OtlpServerError;
use crate::otlp::pipeline::IngestPipeline;

/// Handle to a running gRPC server. The `JoinHandle` resolves when the
/// server task completes (after shutdown signal fires or a hard
/// transport error). The `oneshot::Sender<()>` triggers graceful shutdown.
pub type GrpcServerHandle = (
    tokio::task::JoinHandle<Result<(), OtlpServerError>>,
    oneshot::Sender<()>,
);

/// Bind the gRPC listener on `cfg.listen_grpc` and start serving the 3
/// OTLP collector services. Returns immediately with a join handle +
/// shutdown sender.
///
/// # Errors
/// - [`OtlpServerError::Bind`] if the address is already in use.
/// - [`OtlpServerError::Config`] if `cfg.listen_grpc` is `None` (caller
///   should not call this when gRPC is disabled).
pub async fn serve_grpc(
    cfg: OtlpServerConfig,
    pipeline: Arc<IngestPipeline>,
) -> Result<GrpcServerHandle, OtlpServerError> {
    let addr = cfg.listen_grpc.ok_or_else(|| {
        OtlpServerError::Config("listen_grpc is None; cannot serve gRPC".into())
    })?;

    let logs_svc = LogsServiceServer::new(LogsImpl { pipeline: pipeline.clone() });
    let metrics_svc = MetricsServiceServer::new(MetricsImpl { pipeline: pipeline.clone() });
    let traces_svc = TraceServiceServer::new(TracesImpl { pipeline });

    let (tx, rx) = oneshot::channel::<()>();
    let server = Server::builder()
        .add_service(logs_svc)
        .add_service(metrics_svc)
        .add_service(traces_svc);

    let handle = tokio::spawn(async move {
        // tonic 0.12 serve_with_shutdown takes a future that resolves on shutdown.
        server
            .serve_with_shutdown(addr, async move {
                let _ = rx.await;
            })
            .await
            .map_err(OtlpServerError::from)
    });

    Ok((handle, tx))
}

struct LogsImpl {
    pipeline: Arc<IngestPipeline>,
}

#[tonic::async_trait]
impl LogsService for LogsImpl {
    async fn export(
        &self,
        request: Request<ExportLogsServiceRequest>,

            Err(e) => {

//! Axum HTTP/protobuf server hosting the 3 OTLP collector endpoints.
//!
//! Mirrors [`crate::otlp::server_grpc`] for the OTLP HTTP transport:
//! - POST /v1/logs
//! - POST /v1/metrics
//! - POST /v1/traces
//!
//! All endpoints require `Content-Type: application/x-protobuf` and
//! decode the body as the corresponding `ExportXxxServiceRequest` proto.

use std::sync::Arc;

use axum::{
    body::Bytes,
    extract::State,
    http::{header, HeaderMap, StatusCode},
    response::IntoResponse,
    routing::post,
    Router,
};
use opentelemetry_proto::tonic::collector::{
    logs::v1::{ExportLogsServiceRequest, ExportLogsServiceResponse},
    metrics::v1::{ExportMetricsServiceRequest, ExportMetricsServiceResponse},
    trace::v1::{ExportTraceServiceRequest, ExportTraceServiceResponse},
};
use prost::Message;
use tokio::sync::oneshot;

use crate::otlp::config::OtlpServerConfig;
use crate::otlp::error::OtlpServerError;
use crate::otlp::pipeline::IngestPipeline;

/// Handle to a running HTTP server.
pub type HttpServerHandle = (
    tokio::task::JoinHandle<Result<(), OtlpServerError>>,
    oneshot::Sender<()>,
);

/// Bind the HTTP listener on `cfg.listen_http` and start serving the 3
/// OTLP endpoints.
///
/// # Errors
/// - [`OtlpServerError::Bind`] if the address is already in use.
/// - [`OtlpServerError::Config`] if `cfg.listen_http` is `None`.
pub async fn serve_http(
    cfg: OtlpServerConfig,
    pipeline: Arc<IngestPipeline>,
) -> Result<HttpServerHandle, OtlpServerError> {
    let addr = cfg.listen_http.ok_or_else(|| {
        OtlpServerError::Config("listen_http is None; cannot serve HTTP".into())
    })?;

    let app = Router::new()
        .route("/v1/logs", post(handle_logs))
        .route("/v1/metrics", post(handle_metrics))
        .route("/v1/traces", post(handle_traces))
        .with_state(pipeline);

    let listener = tokio::net::TcpListener::bind(addr).await.map_err(|source| {
        OtlpServerError::Bind { addr, source }
    })?;

    let (tx, rx) = oneshot::channel::<()>();
    let handle = tokio::spawn(async move {
        axum::serve(listener, app)
            .with_graceful_shutdown(async move {
                let _ = rx.await;
            })
            .await
            .map_err(|e| OtlpServerError::Http(format!("axum serve: {e}")))
    });

    Ok((handle, tx))
}

fn require_protobuf_content_type(headers: &HeaderMap) -> Result<(), StatusCode> {
    let ct = headers.get(header::CONTENT_TYPE)
        .and_then(|v| v.to_str().ok())
        .unwrap_or("");
    if !ct.starts_with("application/x-protobuf") {
        return Err(StatusCode::UNSUPPORTED_MEDIA_TYPE);
    }
    Ok(())
}

fn encode_proto_response<M: Message>(resp: M) -> axum::response::Response {
    let body = resp.encode_to_vec();
    ([
        (header::CONTENT_TYPE, "application/x-protobuf"),
    ], body).into_response()
}

//! Shared bearer-token enforcement for gRPC + HTTP servers.

use std::sync::Arc;

use axum::{
    body::Body,
    extract::Request as AxumRequest,
    http::{header, StatusCode},
    middleware::Next,
    response::Response,
};
use tonic::{Request, Status};

const BEARER_PREFIX: &str = "Bearer ";

/// Construct a tonic interceptor that gates every gRPC call on the
/// presence + match of `Authorization: Bearer <expected_token>`.
///
/// When `expected_token` is `None`, returns an interceptor that always
/// passes (no auth required).
pub fn bearer_interceptor(
    expected_token: Option<Arc<String>>,
) -> impl Fn(Request<()>) -> Result<Request<()>, Status> + Clone + Send + Sync + 'static {
    move |req| {
        let Some(expected) = expected_token.as_ref() else {
            return Ok(req);
        };
        let auth = req.metadata().get("authorization")
            .and_then(|v| v.to_str().ok())
            .unwrap_or("");
        if !auth.starts_with(BEARER_PREFIX) {
            return Err(Status::unauthenticated("missing Bearer credentials"));
        }
        if &auth[BEARER_PREFIX.len()..] != expected.as_str() {
            return Err(Status::unauthenticated("invalid Bearer token"));
        }
        Ok(req)
    }
}

/// Axum middleware layer that mirrors [`bearer_interceptor`] for HTTP.
///
/// Returns 401 Unauthorized on missing or invalid bearer.
pub async fn bearer_middleware(
    expected_token: Option<Arc<String>>,
    req: AxumRequest,
    next: Next,
) -> Result<Response, StatusCode> {
    let Some(expected) = expected_token.as_ref() else {
        return Ok(next.run(req).await);
    };
    let auth = req.headers().get(header::AUTHORIZATION)
        .and_then(|v| v.to_str().ok())
        .unwrap_or("");
    if !auth.starts_with(BEARER_PREFIX) {
        return Err(StatusCode::UNAUTHORIZED);
    }
    if &auth[BEARER_PREFIX.len()..] != expected.as_str() {
        return Err(StatusCode::UNAUTHORIZED);
    }
    Ok(next.run(req).await)
}
```

//! rustls server config builder for TLS / mTLS.

use std::path::Path;
use std::sync::Arc;

use rustls::pki_types::{CertificateDer, PrivateKeyDer};
use rustls::server::WebPkiClientVerifier;
use rustls::{RootCertStore, ServerConfig};
use rustls_pemfile::{certs, private_key};

use crate::otlp::error::OtlpServerError;

/// Build a rustls [`ServerConfig`] from cert + key + optional client CA.
///
/// When `client_ca` is `Some`, the server requires + verifies client
/// certificates signed by that CA (mTLS).
///
/// # Errors
/// [`OtlpServerError::TlsConfig`] on any PEM parse / chain validation issue.
pub fn build_server_config(
    cert_path: &Path,
    key_path: &Path,
    client_ca: Option<&Path>,
) -> Result<Arc<ServerConfig>, OtlpServerError> {
    let cert_chain = load_certs(cert_path)?;
    let key = load_key(key_path)?;

    let builder = ServerConfig::builder();

    let cfg = if let Some(ca_path) = client_ca {
        let mut store = RootCertStore::empty();
        for ca in load_certs(ca_path)? {
            store.add(ca).map_err(|e| OtlpServerError::TlsConfig(
                format!("client CA add: {e}").into(),
            ))?;
        }
        let verifier = WebPkiClientVerifier::builder(Arc::new(store))
            .build()
            .map_err(|e| OtlpServerError::TlsConfig(format!("mTLS verifier: {e}").into()))?;
        builder
            .with_client_cert_verifier(verifier)
            .with_single_cert(cert_chain, key)
            .map_err(|e| OtlpServerError::TlsConfig(format!("mTLS with_single_cert: {e}").into()))?
    } else {
        builder
            .with_no_client_auth()
            .with_single_cert(cert_chain, key)
            .map_err(|e| OtlpServerError::TlsConfig(format!("TLS with_single_cert: {e}").into()))?
    };

    Ok(Arc::new(cfg))
}

fn load_certs(path: &Path) -> Result<Vec<CertificateDer<'static>>, OtlpServerError> {
    let file = std::fs::File::open(path).map_err(|source| OtlpServerError::Io {
        path: path.to_path_buf(),
        source,
    })?;
    let mut reader = std::io::BufReader::new(file);
    certs(&mut reader)
        .collect::<Result<Vec<_>, _>>()
        .map_err(|e| OtlpServerError::TlsConfig(format!("cert PEM parse {}: {e}", path.display())))
}

fn load_key(path: &Path) -> Result<PrivateKeyDer<'static>, OtlpServerError> {
    let file = std::fs::File::open(path).map_err(|source| OtlpServerError::Io {
        path: path.to_path_buf(),
        source,

```rust
pub async fn run_idle_sweeper<F, Fut>(self: Arc<Self>, sink: F)
where
    F: Fn(SessionBuffer) -> Fut + Send + Sync + 'static,
    Fut: std::future::Future<Output = Result<(), RouterError>> + Send + 'static,
{
    loop {
        tokio::time::sleep(Duration::from_secs(30)).await;
        let cutoff = Instant::now() - self.idle_timeout;
        let idle: Vec<String> = self.buffers.iter()
            .filter(|e| e.value().try_lock().map_or(false, |g| g.last_seen < cutoff))
            .map(|e| e.key().clone())
            .collect();
        for id in idle {
            if let Some((_, buf_arc)) = self.buffers.remove(&id) {
                if let Ok(buf) = Arc::try_unwrap(buf_arc) {
                    let inner = buf.into_inner();
                    if let Err(e) = sink(inner).await {
                        tracing::error!(session = %id, error = %e, "idle flush sink failed");
                    }
                }
            }
        }
    }
}

pub async fn flush_all<F, Fut>(self: Arc<Self>, sink: F) -> usize
where
    F: Fn(SessionBuffer) -> Fut + Send + Sync + 'static,
    Fut: std::future::Future<Output = Result<(), RouterError>> + Send + 'static,
{
    let ids: Vec<String> = self.buffers.iter().map(|e| e.key().clone()).collect();
    let mut count = 0usize;
    for id in ids {
        if let Some((_, buf_arc)) = self.buffers.remove(&id) {
            if let Ok(buf) = Arc::try_unwrap(buf_arc) {
                let inner = buf.into_inner();
                if sink(inner).await.is_ok() {
                    count += 1;
                }
            }
        }
    }
    count
}
```

async fn run_async(args: IngestOtlpArgs, cli: &crate::Cli) -> anyhow::Result<()> {
    use agentprof_storage::otlp::{
        config::OtlpServerConfig, pipeline::IngestPipeline,
        server_grpc::serve_grpc, server_http::serve_http,
    };
    use agentprof_storage::Db;

    let partial_cfg = crate::config::load_partial_config()?;
    let mut storage_cfg = crate::config::resolve_storage_config(
        &partial_cfg.storage, cli.storage_path.clone(),
    )?;
    let cfg = resolve_otlp_config_from_cli(&args, &partial_cfg.otlp)?;
    cfg.validate().map_err(|e| {
        crate::cmd::ExitKind::UserError.into_anyhow(format!("invalid OTLP config: {e}"))
    })?;

    let db = Arc::new(tokio::sync::Mutex::new(
        Db::open_and_migrate(&storage_cfg.path)
            .map_err(|e| crate::cmd::ExitKind::DataError.into_anyhow(format!("db open: {e}")))?,
    ));
    let pipeline = Arc::new(IngestPipeline::new(db, cfg.session_idle_timeout));

    let grpc = if cfg.listen_grpc.is_some() && !args.no_grpc {
        Some(serve_grpc(cfg.clone(), pipeline.clone()).await?)
    } else { None };
    let http = if cfg.listen_http.is_some() && !args.no_http {
        Some(serve_http(cfg.clone(), pipeline.clone()).await?)
    } else { None };

    if grpc.is_none() && http.is_none() {
        anyhow::bail!("both --no-grpc and --no-http set; nothing to serve");
    }

    // Idle sweeper
    let sweeper = {
        let pipeline = pipeline.clone();
        tokio::spawn(async move {
            let router = pipeline.router();
            let pl2 = pipeline.clone();
            router.run_idle_sweeper(move |buf| {
                let pl = pl2.clone();
                async move { pl.flush_session_buffer(buf).await }
            }).await
        })
    };

    eprintln!("agentprof: ingest-otlp listening (grpc={:?}, http={:?})",
        cfg.listen_grpc, cfg.listen_http);
    tokio::signal::ctrl_c().await?;
    eprintln!("agentprof: SIGINT received; flushing sessions...");

    if let Some((_, tx)) = grpc { let _ = tx.send(()); }
    if let Some((_, tx)) = http { let _ = tx.send(()); }
    sweeper.abort();

    let n = pipeline.router().flush_all({
        let pl = pipeline.clone();
        move |buf| {
            let pl = pl.clone();
            async move { pl.flush_session_buffer(buf).await }
        }
    }).await;
    eprintln!("agentprof: flushed {n} session(s); exit");

    Ok(())
}

  - + First real network surface in storage layer

### Footnote (2026-06-10, M2.2 brainstorm)
