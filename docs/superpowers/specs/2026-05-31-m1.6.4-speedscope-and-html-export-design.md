### 1.2 What changes for users

After M1.6.4:

```sh
# Generate a Speedscope-compatible JSON for upload to https://speedscope.app
agentprof analyze --session <X> --export speedscope > session.speedscope.json

# Generate a self-contained HTML report for sharing (Slack / PR / email)
agentprof analyze --session <X> --export html --output report.html
```

The `--export tui` flag (M1.5) keeps interactive analysis local; the new `--export speedscope` opens the door to richer interactive flamegraphs via the speedscope.app viewer; `--export html` enables async sharing.

## 2. Locked decisions (from brainstorming)

| # | Decision | Rationale |
|---|---|---|
| D-1 | Ship both `speedscope` and `html` in **one** milestone | User choice — keep original M1.6.4 scope as planned |
| D-2 | HTML strategy = **A** (static HTML, no JS) + speedscope JSON as separate "interactive surface" | User choice — each surface does one thing well; simplest implementation |
| D-3 | HTML content = tables + **inline build-time pre-rendered SVG flamegraph** (no JS) | User choice — visual element without runtime cost |
| D-4 | SVG flamegraph is **responsive**: viewBox scales with turn count (30 viewBox units per turn, clamped to 1000–5000), wrapped in `<div style="overflow-x: auto">` | User choice — adapts to short and long sessions |
| D-5 | Color encoding by `ToolSource` (builtin = blue, mcp = purple, hook = orange, skill = green); turns get neutral grey | User choice — coarse but legible |
| D-6 | Activate `askama` 0.16 (workspace dep) for HTML templating; was removed by `fix-askama-unused-dep` so re-add | User choice — proven path |
| D-7 | `SpeedscopeProfile` data type lives in `agentprof-core::export::speedscope` (lib) | User choice — reusable, easily unit-tested |
| D-8 | `SvgFlamegraph` lives in `agentprof-core::export::svg_flamegraph` (lib) | User choice — same justification |
| D-9 | Speedscope unit = `milliseconds` (integer `at`) | Sufficient precision; events.jsonl is RFC3339 with ms granularity |
| D-10 | Speedscope timestamp anchor = **session's first event timestamp = 0**; all `at` are deltas | Reproducible output → snapshot-friendly |
| D-11 | Speedscope frame naming: builtin `<tool>`; MCP `mcp:<server>::<tool>`; hook `hook:<name>`; skill `skill:<name>:<tool>` | Avoid name collision + visible source |
| D-12 | Speedscope frame dedup: globally by `name` (same-named calls share frame index) | Required for speedscope's "left-heavy" view to be meaningful |
| D-13 | Open turns get `ended_at = session-last-event-timestamp` with `(open)` name suffix | Strict event nesting + user-visible status |
| D-14 | Orphan tool calls (no turn_id) → synthetic trailing turn `turn-orphan` | Don't drop data; preserve ADR-0004 orphan semantics |
| D-15 | Span overlap within a turn → **auto-adjust** later call's `started_at` to `prev.ended_at + 1ms` and emit `ExportWarning::SpanAdjustedForSpeedscope` | Preserve data + user-visible signal |
| D-16 | New `ExportWarning` enum in `agentprof-core::export` (NOT pollute `DeriveWarning`) | Single responsibility: derive doesn't adjust spans, export does |
| D-17 | `--section` filter respected for `--export html`, IGNORED for `--export speedscope` (with warn, mirror `--export tui` behavior) | Speedscope is one surface; HTML mirrors md |
| D-18 | `--export html` without `--output` writes to stdout but warns (HTML on terminal is ugly) | Defensive UX without hard-fail |
| D-19 | File extension convention: `.speedscope.json` for speedscope, `.html` for html (doc-only; CLI doesn't enforce) | Ecosystem alignment |

## 3. Scope

### 3.1 In scope

1. `agentprof analyze --export speedscope` → Speedscope evented JSON
2. `agentprof analyze --export html` → self-contained static HTML
3. `SpeedscopeProfile` + `to_speedscope()` in `agentprof-core::export::speedscope`
4. `SvgFlamegraph` + `into_svg_string()` in `agentprof-core::export::svg_flamegraph`
5. `ExportWarning` enum in `agentprof-core::export`
6. Askama HTML template + embedded CSS + print media query
7. New fixture `with-span-overlap` to lock D-15 behavior
8. ADR-0007 documenting D-9 / D-11 / D-12 / D-13 / D-14 / D-15
9. L1 + L2 + L3 docs sync
10. ≈ +12 tests (unit + integration + snapshot)

### 3.2 Out of scope

| Item | Why not |
|---|---|
| Embedded speedscope viewer in HTML | User choice D-2 (excluded) |
| d3.js or any client-side JS | User choice D-3 (no JS) |
| Sortable / filterable tables (client-side) | Print-friendly, no JS |
| Per-tool-name colors (vs per-ToolSource) | User choice D-5 (coarse) |
| Tokenizer-based weights (vs duration_ms) | Events-first pivot — no tokenizer yet (Phase 2) |
| Auto-derived output filename | M1.6.1 precedent — keep `--output` explicit |
| Multi-profile speedscope file (one per turn) | Single-profile hierarchy is the natural fit |
| Sampled speedscope format (vs evented) | Evented matches our open/close event model |
| Validation against speedscope's JSON schema in CI | Round-trip test + smoke test sufficient for MVP |
| HTML themes / dark mode toggles | Print-friendly precludes interactivity |
| Cross-session HTML report | Single-session only; cross-session is M1.6.2 (`aggregate`) |

### 4.2 Behavior matrix

| Flag combination | Behavior |
|---|---|
| `--export speedscope` (default stdout) | Write JSON to stdout |
| `--export speedscope --output X.json` | Write JSON to file X.json |
| `--export speedscope --section ...` | **Warn + ignore** (mirror `--export tui`) |
| `--export speedscope --output X --section ...` | Warn + ignore section; write to file |
| `--export html --output X.html` | Write HTML to file (recommended) |
| `--export html` (no `--output`) | Write HTML to stdout + **warn**: "HTML on terminal is ugly; pass `--output report.html`" |
| `--export html --section turns,tools` | Filter sections (like md) |

### 4.3 Exit codes

Unchanged from M1.4: `0` success / `1` user error / `2` data error / `3` output error / `130` SIGINT. `ExportWarning` does NOT change exit code (it's a warning, not a failure).

## 5. Speedscope JSON mapping

### 5.1 File schema

```jsonc
{
  "$schema": "https://www.speedscope.app/file-format-schema.json",
  "name": "agentprof <session-short-id> <agent>",
  "exporter": "agentprof v<version>",
  "shared": {
    "frames": [
      { "name": "session" },
      { "name": "turn-1" },
      { "name": "bash" },
      { "name": "mcp:github::create_pr" }
      // ...
    ]
  },
  "profiles": [{
    "type": "evented",
    "name": "wall-clock",
    "unit": "milliseconds",
    "startValue": 0,
    "endValue": <session-duration-ms>,
    "events": [
      { "type": "O", "at": 0, "frame": 0 },
      { "type": "O", "at": 12, "frame": 1 },
      { "type": "O", "at": 23, "frame": 2 },
      { "type": "C", "at": 1834, "frame": 2 },
      { "type": "C", "at": 4521, "frame": 1 },
      { "type": "C", "at": <session-duration-ms>, "frame": 0 }
    ]
  }]
}
```

### 5.2 Data flow

```
Episodes + SessionMeta + AnalysisReport
        │
        ▼
agentprof-core::export::speedscope::to_speedscope(...)
        │
        ▼
(SpeedscopeProfile, Vec<ExportWarning>)
        │
        ▼ (agentprof-cli)
serde_json::to_string_pretty + write to stdout / file
        │
        ▼ (stderr) for each ExportWarning
eprintln!("agentprof: warning: ...")
```

### 5.3 Conversion rules

| Source | Speedscope frame | Span origin |
|---|---|---|
| session (root) | `session` | session_meta.started_at → last_event_ts |
| Turn (id=k, ordinal=n) | `turn-<n>` (or `turn-<n> (open)` if `ended_at.is_none()`) | started_at → ended_at OR last_event_ts |
| ToolCall (name="bash", source=Builtin) | `bash` | call.span.started_at → ended_at |
| ToolCall (name="x", source=Mcp{server}) | `mcp:<server>::x` | same |
| HookCall (name="y") | `hook:y` | same |
| SkillInvocation (skill="z", tool="t") | `skill:z:t` | same |
| Orphan ToolCall (turn_id=None) | parent `turn-orphan` (synthetic) appearing AFTER all real turns | call.span unchanged |

### 5.4 Frame dedup algorithm (D-12)

```
build set of all unique frame names (in deterministic order: session, turn-1..N, then BTreeSet of tool/hook/skill names)
emit shared.frames in that order
build name → index map
events reference frames by the map index
```

### 5.5 Overlap adjustment (D-15)

Pseudocode (per turn):

```
last_end = turn.started_at_ms
for call in turn.tool_calls + turn.hook_calls + turn.skill_calls (sorted by span.started_at):
    if call.span.started_at_ms < last_end:
        adjusted = last_end + 1
        push ExportWarning::SpanAdjustedForSpeedscope { tool, original, adjusted }
        emit_open(adjusted, ...)
    else:
        emit_open(call.span.started_at_ms, ...)
    emit_close(max(call.span.ended_at_ms, adjusted+1), ...)
    last_end = max(call.span.ended_at_ms, last_end)
```

This guarantees strict nesting; under-reports timing accuracy only on the rare overlap case.

### 5.6 Open turn handling (D-13)

If `turn.ended_at.is_none()`:
- Frame name suffixed with ` (open)`
- Synthetic close emitted at `last_event_ts`

### 5.7 ExportWarning enum

```rust
// agentprof-core::export::mod.rs
#[derive(Debug, Clone, PartialEq, thiserror::Error)]
#[non_exhaustive]
pub enum ExportWarning {
    #[error("span overlap adjusted for speedscope: tool={tool_name} original={original_start} adjusted={adjusted_start}")]
    SpanAdjustedForSpeedscope {
        tool_name: String,
        original_start: DateTime<Utc>,
        adjusted_start: DateTime<Utc>,
    },
    // (room for future variants: e.g. HTML-specific, CSV-specific)
}
```

## 6. HTML report layout

### 6.1 Page structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>agentprof report — {{ session_short_id }}</title>
  <style>{{ embedded CSS }}</style>
</head>
<body>
  <header>...</header>
  {% if section_includes_flamegraph %}
  <section id="flamegraph">{{ svg_flamegraph_str }}</section>
  {% endif %}
  {% if section_includes_turns %}
  <section id="turns">{{ turn_summary_table }}</section>
  {% endif %}
  {% if section_includes_tools %}
  <section id="tools">{{ tool_rank_table }}</section>
  {% endif %}
  {% if section_includes_hooks %}
  <section id="hooks">{{ hook_rank_table }}</section>
  {% endif %}
  <section id="warnings">{{ warnings_block }}</section>
</body>
</html>
```

### 6.2 SVG flamegraph (D-4, D-5)

Generated by `agentprof-core::export::svg_flamegraph`:

| Attribute | Value |
|---|---|
| viewBox W | `clamp(1000, turn_count × 30, 5000)` (viewBox units) |
| viewBox H | `50 × (max_depth + 1)` (e.g., 4 levels = 200 units) |
| CSS | `width: 100%; height: auto` |
| Wrapper | `<div style="overflow-x: auto">` (long sessions scroll horizontally) |
| Row 0 | Single rect spanning full width: "session" (grey #6b7280) |
| Row 1 | One rect per turn, x-positioned by `(turn.started_at - session_start) / total_duration × viewBox_W` with width `(turn_duration / total_duration) × viewBox_W` (idle gaps between turns get no rect; grey #9ca3af) |
| Rows 2+ | One rect per tool/hook/skill call, x-positioned by `(span.started_at - session_start) / total_duration × viewBox_W` |
| Color (Row 2+) | Builtin = #3b82f6 (blue); MCP = #a855f7 (purple); Hook = #f97316 (orange); Skill = #10b981 (green) |
| Frame text | sans-serif 12px; truncate to fit; rect carries `<title>` for tooltip |
| Frame skip | `<rect>` always rendered; `<text>` skipped if rect width < 30 viewBox units |

### 6.3 CSS embedding

`crates/agentprof-cli/src/cmd/format/templates/styles.css` → `include_str!` into `<style>` block at template compile time.

Print media query collapses interactive bits (which we don't have, but future-proof):

```css
@media print {
  #flamegraph { page-break-after: always; }
  table { font-size: 9pt; }
}
```

### 6.4 Table rendering

Direct `<table>` per `TurnSummaryRow` / `ToolRankRow` / `HookRankRow`. Mirror md report column order. Numeric cells right-aligned, monospace tabular-nums.

## 12. Risks & follow-ups

### 12.1 Risks (with mitigations)

| Risk | Mitigation |
|---|---|
| Speedscope evented format rejection by speedscope.app due to unforeseen edge case | T1 includes a strict-nesting unit test on all 12 fixtures; smoke test uploads to speedscope.app manually as part of acceptance |
| `askama` 0.16 has breaking changes from older spec memory | Pin to `0.16.x`; askama compiles templates at build time so errors are caught at `cargo build`, not runtime |
| SVG too wide / too tall for some sessions | viewBox is clamped 1000–5000; `overflow-x: auto` wrapper; max_depth clamped to 4 |
| HTML report size exceeds practical email limits (e.g. > 500 KB) for very large sessions | Estimated 60 KB for 100-turn session; size scales linearly; if it becomes an issue, follow-up could add `--compact` flag |
| Span overlap is more frequent than expected → spam warnings | Currently rare per ADR-0004 observation; if frequent, follow-up could de-duplicate adjacent warnings per tool name |
| Adding `askama` re-introduces a dep that was deliberately removed | Document in ADR-0007 + CHANGELOG: it's NOW USED, not unused |

### 12.2 Deferred follow-ups (M1.6.5+ candidates)

1. CSV export — `--export csv` for tool ROI table import to spreadsheets
2. Cross-session HTML report — needs M1.6.2 (`aggregate`) first
3. Speedscope sampled format (for future tokenizer-based weight axis)
4. Interactive HTML with d3-flame-graph — re-evaluate after user feedback on static SVG
5. Embed speedscope viewer in HTML (option B from brainstorming) — re-evaluate

## 14. Glossary

- **Speedscope evented format**: JSON with an array of {type:"O"|"C", at:<time>, frame:<idx>} events referencing globally-deduped frames in `shared.frames`. Specs: https://github.com/jlfwong/speedscope/blob/main/file-format.md
- **Frame**: a labeled unit (function / turn / tool call) referenced by index from event records
- **Orphan tool call**: `ToolCall.turn_id == None` — derive layer couldn't attribute the call to any open turn
- **Open turn**: `Turn.ended_at == None` — the session ended (or was truncated) before we saw `turn.end`
- **askama**: compile-time Rust template engine (Jinja-like syntax)
- **ExportWarning**: new enum in `agentprof-core::export`; surfaced on stderr by cli, doesn't change exit code
