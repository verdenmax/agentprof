# M1.4 CLI + analyzer rollups — design

## 1. One-liner

**M1.4 = "终端用户首次可用版本"。** 增加 3 个 analyzer 在 Episodes 之上做 rollup（`turn_summary` / `tool_rank` / `hook_rank`），实现 `agentprof analyze` CLI 子命令支持 md/json 导出，并消化 M1.3 留下的 placeholder 限制（让 Episode 的 tool/hook/skill 显示真实名字而非 event id）+ commit-call-turn-divergence P0 follow-up。

## 2. Context / why now

M1.3 合并到 main（merge commit `2eea686`，2026-05-28），ship 了：
- `agentprof_core::episode` 模块 + 5 个 Episode 类型 + `derive_episodes` 纯函数
- 10 个新 CopilotEvent 变体 + Tool 系列 payload 扩展（Unknown 92% ↓，Json 35% ↓）
- xtask `schema-audit` 长期可重跑工具
- `CallRef { name, index }` 自描述 back-reference

但**终端用户仍无可见输入**：没有 CLI 子命令，库层结果只能通过手写 Rust demo 看到。M1.4 把"分析"链路打通到用户。

### 三个 M1.3 遗留必须先解

1. **Event trait 不暴露 payload name → derive_episodes 用 `event.id()` 占位** → analyzer 按 name 聚合时每个 tool/hook/skill 都变成"独立的一种"。必须先扩 trait。
2. **commit-call-turn-divergence** (P0 from M1.3 final review)：tool 跨 turn 边界时 turn_id 和 back-reference 不一致 → turn_summary 的 per-turn tool count 会失真。必须修。
3. CHANGELOG 还没有 M1.4 的 user-facing 入口；根 `README.md` 还没 Quick start（因为之前没法 demo）。

### 出现的边界问题（M1.3 顺带留 P2）

- `classifier-zip-fix`（xtask audit zip alignment）
- `negative-duration-span`（非单调时间戳）
- `tooltelemetry-restricted-props-skip-if`（null 序列化）

**M1.4 不强行解决 P2**；如果实现过程中自然触碰则顺手；否则推到 M1.5+。

## 3. Goals & Non-Goals

### 3.1 Goals

- **G1**：`agentprof analyze` 能在终端运行并产出 markdown 报告，covering 当前 ~/.copilot/session-state 实数据
- **G2**：3 个 analyzer rollup 函数（turn_summary / tool_rank / hook_rank）作为 `agentprof-core::analyzer` 公开 API
- **G3**：`Event` trait 增加 `payload_name() -> Option<&str>` 默认实现 None；CopilotEvent 给 tool.* / hook.* / skill.invoked 返回真实 payload name
- **G4**：derive_episodes 使用 `payload_name()`；M1.3 fixture snapshot 全部更新为真实名字
- **G5**：commit-call-turn-divergence P0 修复 → tool/hook 的 turn 归属一致
- **G6**：md export（终端可读、表格化）+ json export（机读、Serialize）
- **G7**：3 个 CLI 退出码场景验证（0/1/2/130）；--output 写文件路径正确
- **G8**：所有 gates 全绿（fmt / clippy -D warnings / test / rustdoc -Dwarnings / cargo deny）
- **G9**：根 `README.md` 加 Quick start section（首次有可演示功能）
- **G10**：L1/L2/L3 文档同 PR 同步（ADR-0005 新增、architecture.md §6+§8 填充、agentprof-cli/README.md 新建、core/README.md 加 analyzer 段、CHANGELOG）

### 3.2 Non-Goals（M1.4 显式不做）

- ❌ `skill_rank` / `aggregate` analyzer → M1.5+
- ❌ `agentprof list` / `agentprof aggregate` / `agentprof watch` 子命令 → M1.5+
- ❌ csv / speedscope / html 导出 → M1.5-M1.6
- ❌ TUI（火焰图、ROI 表）→ M1.5
- ❌ SQLite 持久化 / OTLP receiver → Phase 2
- ❌ Token rollups / waste_estimate_usd / schema_utilization → Phase 2 per ADR-0001
- ❌ Claude / Codex adapter → Phase 2/3
- ❌ M1.3 P2 follow-ups 主动修（顺手碰到才修）
- ❌ Schema audit 报告输出的进一步分类增强 → M1.5+ 可选

### 6.3 CLI enums

```rust
// agentprof_cli::cmd::analyze
#[derive(Args, Debug, Clone)]
#[non_exhaustive]
pub struct AnalyzeCmd {
    #[arg(long, default_value = "copilot")]
    pub agent: AgentKind,

    #[arg(long, default_value = "latest")]
    pub session: SessionSelector,

    #[arg(long)]
    pub root: Option<PathBuf>,

    #[arg(long, default_value = "md")]
    pub export: ExportFormat,

    #[arg(long)]
    pub output: Option<PathBuf>,

    #[arg(long, value_delimiter = ',', default_values_t = AnalysisSection::all().to_vec())]
    pub section: Vec<AnalysisSection>,
}

#[derive(Debug, Clone, ValueEnum)]
pub enum ExportFormat { Md, Json }

#[derive(Debug, Clone, ValueEnum, PartialEq, Eq)]
pub enum AnalysisSection { TurnSummary, ToolRank, HookRank }

impl AnalysisSection {
    pub const fn all() -> &'static [Self] {
        &[Self::TurnSummary, Self::ToolRank, Self::HookRank]
    }
}

// SessionSelector 需要自定义 FromStr 因为不是简单 enum
#[derive(Debug, Clone)]
pub enum SessionSelector {
    Latest,
    Previous,
    Uuid(String),
    Path(PathBuf),
}

impl std::str::FromStr for SessionSelector {
    type Err = String;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s {
            "latest" => Ok(Self::Latest),
            "previous" => Ok(Self::Previous),
            _ if s.contains('/') || s.contains('\\') => Ok(Self::Path(PathBuf::from(s))),
            _ if uuid_like(s) => Ok(Self::Uuid(s.to_string())),
            _ => Err(format!("不识别的 session 标识：{s}（用 'latest' / 'previous' / UUID / 路径）")),
        }
    }
}

fn uuid_like(s: &str) -> bool {
    // 简单启发：含 8-4-4-4-12 形态
    s.len() == 36 && s.chars().filter(|c| *c == '-').count() == 4
}
```

## 7. Algorithms

### 7.1 percentile 计算（tool_rank / hook_rank 用）

```rust
fn percentile(sorted_durations: &[Duration], pct: f64) -> Duration {
    if sorted_durations.is_empty() {
        return Duration::zero();
    }
    let idx = ((pct / 100.0) * (sorted_durations.len() as f64 - 1.0)).round() as usize;
    let idx = idx.min(sorted_durations.len() - 1);
    sorted_durations[idx]
}

fn collect_durations(calls: &[ToolCall]) -> Vec<Duration> {
    let mut v: Vec<Duration> = calls.iter().map(|c| c.span.duration()).collect();
    v.sort_unstable();
    v
}

// p50 = percentile(50.0); p95 = percentile(95.0); max = sorted.last().unwrap_or(zero)
```

特殊情况：
- 0 个 call → 不该出现在 ranking（filter 掉）
- 1 个 call → p50 = p95 = max = 单个值
- 2+ calls → 标准百分位

### 7.2 commit-call-turn-divergence 修复

**旧代码**（M1.3）：
```rust
// commit_tool_call:
if let Some(turn_idx) = self.open_turn_idx {  // ← end-time turn
    self.turns[turn_idx].tool_calls.push(CallRef::new(name.into(), new_idx));
}
```

**新代码**（M1.4）：
```rust
// commit_tool_call: 用 ToolCall 自身记录的 turn_id (start-time turn) 反查 turns 索引
if let Some(turn_id) = &call.turn_id {
    if let Some(turn_idx) = self.turns.iter().rposition(|t| &t.id == turn_id) {
        self.turns[turn_idx].tool_calls.push(CallRef::new(name.into(), new_idx));
    }
}
```

`rposition` 从尾向头找第一个匹配，因为最近开的 Turn 最可能匹配（O(K) 期望 K 小）。同样改动应用到 `commit_hook_call`。

**OpenSkill 没有 turn_id**（skill 是 instant event，没 span），保持现状用 self.open_turn_idx 即可。

新 fixture `cross-turn-tool/` 触发：
```
turn-A start
tool-X start (in turn-A)
turn-A end
turn-B start
tool-X complete (now in turn-B; was in turn-A at start)
turn-B end
```

旧逻辑：tool 进 turn-B.tool_calls（错）
新逻辑：tool 进 turn-A.tool_calls（对）+ turn-A 现已 Completed，但 tool_calls Vec 可写

### 7.3 SessionSelector 解析

```
SessionSelector::Latest    → adapter.discover_sessions(root)[0]
SessionSelector::Previous  → adapter.discover_sessions(root)[1] (else error)
SessionSelector::Uuid(s)   → filter discover by sref.id == s (else error)
SessionSelector::Path(p)   → SessionRef::new(uuid_from_dir(p), agent, p, mtime, size, has_inuse_lock)
```

UUID lookup 失败时 stderr 输出可用 UUIDs head 5 个 + exit 1。

## 11. Risks & Open Questions
